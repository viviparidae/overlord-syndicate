# Overlord Syndicate (オーバーロード・シンジケート)

> **「1990年代、シャッター商店街の冴えない息子に転生した魔王は、泥臭い情報工作と電波ジャックで現代社会をハックする。」**

`Overlord Syndicate` は、1990年代の日本を舞台に、魔王として現代社会へ降臨したプレイヤーが、アナログな情報網、圧倒的な演説、そして非道な経営戦略（サイコパシー）を駆使して世界を裏から侵食・掌握していく**横スクロールADV × 社会侵食シミュレーションゲーム**です。

---

## ── Concept

既存の作品にありがちな「異世界ファンタジー」や「日常系コメディ」ではありません。

本作品では、**「効率を追求するゲーマーの冷徹な思考（＝サイコパシー）」**そのものを魔王の思考と完全同期させます。情や倫理観を排し、1990年代特有の空気感（バブル崩壊後の陰鬱さ、ポケベル、テレホンクラブ、深夜ラジオ）の中で、人間関係・ローカルメディア・法律・群衆心理をただの「リソース」としてハックする悪徳の快感を提供します。

---

## ── Game Systems & Flow

### 1. 主人公 ＝ プレイヤーの完全同期

- 特別なメタ発言はありません。プレイヤーが「ゲームを最短・最高効率で攻略しようとする冷徹な判断」そのものが、そのまま魔王としての正解（サイコパシー）になります。
- 効率の悪いNPCは容赦なく切り捨てる、その冷酷なプレイスタイルがそのまま物語を進行させます。

### 2. 二面性パラメーター（「完璧な善人」の仮面）

- **表の顔（日常・横スクロールADVパート）:** 昼は実家の文房具店を切り盛りし、商店街で「礼儀正しく優秀な息子」を演じることで、警察や行政の警戒度（サスペクト）を低く抑えます。
- **裏の顔（裏工作・侵食パート）:** 日常会話や客の噂話から得たスキャンダルや弱みを元に、裏社会の権力構造を書き換えていきます。

### 3. 3つの核心リソース

- **資金 (JPY):** 表の店舗経営、不動産買収、政財界への工作資金。
- **恐怖 (Fear):** 相手を脅迫・屈服させて従わせる力。（上昇しすぎると警察の警戒度が悪化）
- **狂信 (Faith):** 演説や情報操作で獲得する民衆の熱狂。無償で動く手駒や支持率に変換。

### 4. 支配の拡大ロードマップ（フェーズ）

1. **Phase 1: 1990年代のシャッター商店街**
   - 実家の文房具店を拠点に、店に来る子供や主婦から地域の噂・スキャンダルを収集。悪徳地主や競合を追い落とし、地域社会を裏から傀儡化。
2. **Phase 2: 地方都市（深夜ラジオ・ローカルTVハック）**
   - 深夜ラジオのパーソナリティや地方局の電波をジャック。自作自演の事件と、民衆の不安を煽る「パフォーマンス演説」で世論を狂信へと導く。
3. **Phase 3: 首都・国家（国家ハック）**
   - 全国ネットのメディア支配、大企業の買収、大規模デモのコントロールを通じて合法的に国家権力を掌握。
4. **Phase 4: グローバル（新世界秩序）**
   - 世紀末の世界金融と情報網を支配し、現代社会そのものを自らの「魔王城」へと塗り替える。

## ── Screen Layout & UI

ブラウザ上でスムーズに動作させるため、Phaser.jsによる横スクロール画面と、HTML/CSSによるレトロなステータス管理パネルを組み合わせたレイアウトを採用しています。

```text
+-------------------------------------------------------+
| [資金: ¥10,000] [恐怖: 0] [狂信度: 5%] [警戒度: 0%]      | <- ステータスバー
+-------------------------------------------------------+
|                                                       |
|   🏠 1990年代・シャッター商店街（横スクロール画面）       | 
|   [文房具店]                   [怪しい路地裏]         |
|   🚶(主人公)                   👤(ターゲットの客)     |
|                                                       |
+-------------------------------------------------------+
| コマンド・裏工作パネル                                  |
| [ 店番をする ]  [ 噂を流す ]  [ 地主を脅迫する ]      | <- 操作パネル
+-------------------------------------------------------+
| ログコンソール:                                       |
| > 1990年・裏社会侵食シミュレーションを開始します。      |
+-------------------------------------------------------+
```

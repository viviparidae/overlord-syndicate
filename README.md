# Overlord Syndicate (オーバーロード・シンジケート)

> **「商店街の冴えない息子は、現代社会をハックする魔王だった。」**

`Overlord Syndicate` は、現代社会へ降臨した魔王となり、圧倒的なカリスマ、演説、そして非道な経営戦略（サイコパシー）を駆使して世界を裏から侵食・掌握していく**現代社会掌握・経営シミュレーションゲーム**です。

---

## ── Concept

既存の作品にありがちな「異世界ファンタジー」や「日常系コメディ」ではありません。

本作品では、**「効率を追求するゲーマーの冷徹な思考（＝サイコパシー）」**そのものを魔王の思考と完全同期させます。情や倫理観を排し、人間関係・メディア・法律・群衆心理をただの「リソース」としてハックする悪徳の快感を提供します。

---

## ── Game Systems

### 1. 3つの核心リソース
* **資金 (JPY):** 表の店舗経営、不動産買収、政財界への工作資金。
* **恐怖 (Fear):** 相手を脅迫・屈服させて従わせる力。（上昇しすぎると警察や国家の警戒度が悪化）
* **狂信 (Faith):** 演説や情報操作で獲得する民衆の熱狂。無償で動く手駒や支持率に変換。

### 2. 支配の拡大ロードマップ
1. **Phase 1: シャッター商店街（フロント企業経営）**
   * 実家の文房具店を拠点に、店に来る客の悩みやスキャンダルを収集。競合店や地主を追い落とし、地域社会を裏から傀儡化する。
2. **Phase 2: 地方都市（行政・メディア掌握）**
   * 地方TV局やSNSメディアを買収。自作自演の事件と圧倒的な「パフォーマンス演説」で世論を煽動し、警察や地方自治体を無力化。
3. **Phase 3: 首都・国家（国家ハック）**
   * 全国ネットの電波ジャック、大企業の買収、大規模デモのコントロール。法改正を推し進め、合法的に国家権力を握る。
4. **Phase 4: グローバル（新世界秩序）**
   * 世界金融と情報網を支配し、現代社会そのものを自らの「魔王城」へと塗り替える。

### 3. メディア・パフォーマンス（演説システム）
テレビ生放送やSNS配信を電波ジャックし、群衆の「不安」「怒り」「依存心」を狙いすました言葉で刺激。正論ではなく過激な煽動によって、世論の狂信度を爆発的に上昇させます。

---

## ── Key Features

* **主人公 ＝ プレイヤーの完全同期**
  * 特別なメタ発言はなく、プレイヤーが「ゲームを最短・最高効率で攻略しようとする冷徹な判断」そのものが、そのまま魔王としての正解（サイコパシー）になるゲーム設計。
* **二面性パラメーター（「完璧な善人」の仮面）**
  * 昼は「健気で優秀な商店の息子」として振る舞い警察の警戒度を抑え、夜は裏社会の権力構造を書き換える不気味な落差。

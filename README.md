# Overlord Syndicate (オーバーロード・シンジケート)

> **「1990年代、シャッター商店街の冴えない息子は、弁論という名の討論で他人の嘘を解体していく。」**

`Overlord Syndicate` は、1990年代の日本を舞台に、文房具店の三代目店主が
商店街のいざこざを「まとめ役」として裁きながら、少しずつ街の権力を握っていく
**横スクロール調査 × 弁論アドベンチャー**です。

設計ドキュメントの入口: [`docs/index.md`](docs/index.md)

---

## ── Concept

> **ネタバレ注意（開発用）**: 主人公は魔王が人間として転生した存在であり、高知能のサイコパス。
> ただし第1章では、その内面も正体もプレイヤーには開示されない。叙述規約は
> [`docs/04_lore/narrative-rules.md`](docs/04_lore/narrative-rules.md) を参照。

既存の作品にありがちな「異世界ファンタジー」や「日常系コメディ」ではありません。

本作品では、**「効率を追求するプレイヤーの冷徹な思考」**そのものを主人公の思考と同期させます。
情や倫理観を排し、1990年代特有の空気感（バブル崩壊後の陰鬱さ、ポケベル、公衆電話、深夜ラジオ）の中で、
人間関係・噂・証言のズレを「材料」として扱う快感を提供します。

## ── Game Systems & Flow

### 1. 三層構造

すべての章は次の順で進みます。

1. **導入（ストーリー）** — ADV形式。失敗要素なし。事件と人物関係を提示。
2. **調査（横スクロール）** — 商店街を歩き、聞き込みと痕跡調べで証拠を集める。
3. **解決（弁論）** — 商店街組合の臨時総会。証言のほころびを証拠で突く。

### 2. 調査パート

- 横スクロールの1ロケーションを移動し、ホットスポットを調べる。
- 「日常の視点」と「洞察の視点」の2層。洞察では、言葉の裏と物の不自然さが見える。
- 調査に失敗はなく、時間制限もない。必須証拠は必ず入手できる。

### 3. 解決パート

- 証言はブロック単位で提示され、各ブロックに最大1つのほころびがある。
- 「問い返し」で詳細を掘り、「差し出し」で証拠を突きつける。
- **誤答はミスカウント。上限（章1は3回）に達するとゲームオーバー。**
- リトライは「解決パート冒頭」または「章の最初」から。証拠は保持される。

数値リソース（資金・恐怖・狂信・警戒度）による管理は行いません。

### 4. 支配の拡大ロードマップ（フェーズ）

1. **Phase 1: 1990年代のシャッター商店街** — 万引き常習犯の更生、地主との対峙。
2. **Phase 2: 地方都市** — 商店会連合、深夜ラジオ・地方局。
3. **Phase 3: 国家（中央）** — 業界団体、官僚、全国メディア。
4. **Phase 4: 都市国家（国際都市連合）** — 各国代表、国際機関。

プロトタイプ第二弾（`proto/v2`）は第1章のみを対象とします。

## ── Screen Layout & UI

論理解像度は 960 × 540（`Scale.FIT`、`pixelArt: true`）。
描画は Phaser、HUD・ポーズ・ゲームオーバーは DOM オーバーレイ。

```text
+-------------------------------------------------------+
| 第一話 怒られたい少年                  証拠 3/8  [≡] |
+-------------------------------------------------------+
|                                                       |
|   商店街・中央通り（横スクロール）                     |
|   [文房具店]        [アーケード]        [組合事務所]   |
|        🚶(主人公)      👤(住人)                        |
|                                                       |
+-------------------------------------------------------+
| 郷田 権造                                              |
| 「あの子には不自由させておらん。塾の時間に店へ来るはずが…」 |
|                                              ▼         |
+-------------------------------------------------------+
```

解決パートでは、証言ブロック・ミスカウント（`○ ○ ○`）・証拠品／問い返し／差し出しの各ボタンを表示します。
詳細は [`docs/02_game-spec/01_flow-ui/hud-controls.md`](docs/02_game-spec/01_flow-ui/hud-controls.md)。

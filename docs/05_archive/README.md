# アーカイブ・ボツ案

採用しなかった案は削除せず、ここに理由付きで残す。再検討の際は前提が変わっていないか確認する。

## 1. 第一弾の設計（`proto/v1`）

- リソース管理（資金／恐怖／狂信／警戒度）による進行。
- 警戒度100でゲームオーバー。
- コマンド選択型のターミナル画面。
- 却下理由: プロトタイプ第二弾では、失敗の重みを解決パートのミスカウントに一本化するため。
- コードは `proto/v1` ブランチに保存。本ブランチには引き継がない。

## 2. 没にした案（第二弾）

| 案 | 却下理由 |
| --- | --- |
| 洞察視点（視点切替で隠れたホットスポットを見る） | 『都市伝説解体センター』の念視に近く模倣と受け取られるため、章1実装後に撤去。観察は台詞と地の文で表現する |
| 商店街を4画面以上に拡張 | 探索密度が薄まり、プロトタイプの作業量に不釣り合い |
| 解決パートで「保留」を廃止 | 詰みが発生するため |
| 差し出しのドラッグ&ドロップ | タッチ操作で誤爆が増える。2タップ選択に統一 |
| 章選択のない一直線進行 | 章単位のリトライとプレイテストに不便 |
| オートモードを解決パートにも適用 | 誤答の責任をプレイヤーに帰属させる方針に反する |

## 3. 保留（再検討の余地あり）

- 解決パートの制限時間。テンポは上がるが、読みの時間を奪う。
- 証言者を切り替える「尋問パート」の追加。章3以降で検討。
- 章跨ぎの証拠持ち越し。プロトタイプでは0件だが、章2で必要になる可能性。

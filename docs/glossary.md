# 用語集

## 1. 核心リソース

| 用語   | 内部名    | 定義                                                     |
| ------ | --------- | -------------------------------------------------------- |
| 資金   | `funds`   | 店運営・賄賂・不動産買収・工作資金                       |
| 恐怖   | `fear`    | NPC を脅迫・屈服させる力。上昇しすぎると警戒度が悪化する |
| 狂信   | `faith`   | 民衆の熱狂。無償の手駒・支持率に変換される               |
| 警戒度 | `suspect` | 警察/行政の注目度。100 でゲームオーバー                  |

## 2. 二面性パラメーター

| 用語   | 内部名        | 定義                                               |
| ------ | ------------- | -------------------------------------------------- |
| 表の顔 | `publicFace`  | 日常パート。文房具店接客など。警戒度低下、資金獲得 |
| 裏の顔 | `privateFace` | 侵食パート。裏工作。恐怖/狂信獲得、警戒度上昇      |

## 3. フェーズ

| 用語    | 内部名   | 定義                                 |
| ------- | -------- | ------------------------------------ |
| Phase 1 | `phase1` | シャッター商店街（実家の文房具店）   |
| Phase 2 | `phase2` | 地方都市（深夜ラジオ・ローカルTV）   |
| Phase 3 | `phase3` | 首都・国家（全国ネット・大企業買収） |
| Phase 4 | `phase4` | グローバル（世界金融・情報網）       |

## 4. 1990年代特有の用語と表現

| 用語             | 定義                                                   |
| ---------------- | ------------------------------------------------------ |
| ポケベル         | 携帯情報端末。緊急連絡手段として使用                   |
| テレホンクラブ   | 電話を通じた出会いシステム。情報収集の一環             |
| 深夜ラジオ       | 夜間放送のラジオ局。世論操作・狂信獲得に使用           |
| 平成             | 1989-2019 年間の日本年号                               |
| シャッター商店街 | 空き家・廃墟になった商店街。バブル崩壊後の陰鬱さを象徴 |

## 5. アクション名

| 用語       | 内部名        | 定義                                         |
| ---------- | ------------- | -------------------------------------------- |
| 店番をする | `runShop`     | 文房具店での接客。資金獲得、警戒度低下       |
| 噂を流す   | `spreadRumor` | 噂情報を流す。狂信獲得、警戒度上昇           |
| 脅迫する   | `intimidate`  | 相手を脅迫し屈服させる。資金獲得、警戒度上昇 |

> **注意:** キー名（`funds`, `fear` など）は英語のまま維持。日本語テキストは `src/localization/` で管理。

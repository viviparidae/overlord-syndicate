# 舞台スケール設計

物語は商店街の内輪のいざこざから始まり、最終的には都市国家の利害へ広がる。
**弁論の構造は変えず、場の呼称・参加者・証拠の種類だけをスケールさせる。**

## 1. 不変条件（全スケール共通）

| 項目 | 内容 |
| --- | --- |
| 三層構造 | 導入 → 調査 → 解決（弁論） → エピローグ |
| 弁論の手順 | 証言 → 問い返し → ほころびの指摘（差し出し） |
| 失敗 | ミスカウント上限でゲームオーバー（章ごとに設定） |
| 分岐 | なし。章ごとに結末は1つ |
| リソース | なし（フラグ・証拠・ミスカウントのみ） |
| プレイヤーの立場 | 表向きは「公平な第三者」。実態は次章の材料を集めている |

規模が上がっても**操作とルールは変えない**。変わるのは「誰が、どこで、何を証拠にするか」だけ。

## 2. スケール梯子

| Phase | 単位 | 弁論の場 | 参加者 | 主人公の立場 | 章の目安 |
| --- | --- | --- | --- | --- | --- |
| 1 | 商店街（自治会・組合） | 組合の臨時総会 | 商店主、地主、住人 | 被害店主の代表（まとめ役） | 1〜3 |
| 2 | 地方都市（市） | 公開討論会・市の公聴会 | 商店会連合、市民団体、地方局 | 市民側の立会人 | 4〜6 |
| 3 | 国家（中央） | 審議会・公聴会 | 業界団体、官僚、全国メディア | 参考人（有識者） | 7〜9 |
| 4 | 都市国家（国際都市連合） | 都市国家の評議会 | 各都市国家の代表、国際機関 | 提案者・議長 | 10〜12 |

- 上に行くほど**観客が増え、証言の責任が重くなる**。ミスカウントの上限は 3 前後で維持し、代わりに証言ブロック数と証拠の読み応えで難度を上げる。
- 立場は「まとめ役 → 立会人 → 参考人 → 議長」と変わるが、**呼び名は章データで持ち、コードは共通**とする。

## 3. スケールごとの差分

| 項目 | Phase 1 | Phase 2 | Phase 3 | Phase 4 |
| --- | --- | --- | --- | --- |
| 証言者数 | 3〜4 | 4〜5 | 5〜6 | 6〜8 |
| 証言ブロック | 10〜12 | 12〜16 | 16〜20 | 20〜26 |
| ほころび | 3 | 4〜5 | 5〜6 | 6〜8 |
| 証拠の種類 | 帳簿、VHS、レシート | 議事録、録音テープ、写真 | 公文書、予算書、記者会見録 | 条約案、統計、通信記録 |
| 会場の見た目 | 事務所の机 | 公民館・ホール | 会議室・議場 | 円卓・同時通訳 |
| 観客 | 住人10人程度 | 市民数十人 | 報道陣 | 各国代表・中継 |

- 証拠が「紙」から「録音」「公文書」「条約」へ移るだけで、**集める・差し出す・問い返す**の手触りは変えない。

## 4. 呼称のルール

- UI・システム名は「**弁論**」で統一する（`resolution` シーン、`ui.resolution.*`）。
- 画面上の見出しは章データの `venueKey` で切り替える。

| Phase | `venueKey` | 表示例 |
| --- | --- | --- |
| 1 | `venue.assembly` | 臨時総会 |
| 2 | `venue.hearing` | 公開討論会 |
| 3 | `venue.council` | 審議会 |
| 4 | `venue.assembly_of_cities` | 都市国家評議会 |

- 章データに `scale: 1..4` と `venueKey` を持たせる。コード側は分岐せず、表示だけ差し替える。

## 5. 章データへの追加

`src/data/chapters/chNN/index.ts`（予定）に次を追加する。

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `scale` | `1 \\| 2 \\| 3 \\| 4` | 舞台スケール |
| `venueKey` | string | 弁論の場の表示名キー |
| `roleKey` | string | 主人公の立場の表示名キー（`role.summarizer` など） |

既存の `missLimit` / `requiredEvidence` / `testimonies` は変更しない。

## 6. 使わない語

- 「法廷」「裁判」「弁護士」「検察」「被告人」「異議あり」。スケールが上がっても法廷劇にしない。
- 「裁判所」ではなく「総会」「公聴会」「審議会」「評議会」。**話し合いの場**として描く。

## 7. 未決事項

- Phase 4 の「都市国家」の具体像（実在の都市国家を模さない架空の連合にするか）
- Phase 2 の舞台を「市」にするか「商店会連合」にするか（章4の事件次第）
- 立場の呼称を章ごとに変えるか、全章「議事進行役」で統一するか

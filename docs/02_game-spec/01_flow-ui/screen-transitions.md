# 画面遷移図

## 1. 全体図

```
[Title]
   │ はじめから / つづきから / 章選択
   ▼
[Chapter Select] ──(未解放章はロック表示)──▶ [Title]
   │
   ▼
[Intro: ADV]  ── クリック/決定で送り ──▶ [Investigation]
                                              │ 必要証拠が揃った
                                              ▼
                                        [Resolution: 弁論]
                                          │      │        │
                              正解進行 ───┘      │        └─── ミス上限到達
                                                 │                 │
                                                 ▼                 ▼
                                          [Chapter Result]   [Game Over]
                                                 │                 │
                                                 │        「解決パートからやり直す」
                                                 │        「章の最初から」
                                                 ▼                 ▼
                                          [Epilogue: ADV]    (該当パートへ)
                                                 │
                                                 ▼
                                          [Chapter Select]（次章解放）
```

## 2. 画面一覧

| ID | 画面 | 種別 | 入力 | 備考 |
| --- | --- | --- | --- | --- |
| `title` | タイトル | DOM/Phaser | 決定、上下 | BGMなし（無音） |
| `chapterSelect` | 章選択 | DOM | 左右、決定 | 進行度をセーブから読む |
| `intro` | 導入ADV | Phaser | 決定、スキップ | 失敗なし。既読スキップ対応 |
| `investigation` | 調査 | Phaser | 移動、調べる、話す、証拠品 | 遷移は「移動」のみ |
| `resolution` | 弁論 | Phaser + DOM | 決定、問い返し、差し出し、証拠品 | ミスカウント表示 |
| `evidenceDetail` | 証拠品詳細 | DOMオーバーレイ | 決定、戻る | どの画面からも開ける |
| `pause` | ポーズメニュー | DOM | 上下、決定 | セーブ、設定、章選択へ |
| `gameOver` | ゲームオーバー | DOM | 上下、決定 | 再開地点を選ぶ |
| `chapterResult` | 章結果 | DOM | 決定 | 正答数、所要時間、称号（演出のみ） |
| `epilogue` | エピローグADV | Phaser | 決定、スキップ | 結末は章ごとに固定 |

## 3. 遷移の原則

- **調査パートから解決パートへは戻れない。** 解決開始時にチェックポイントを保存する。
- **解決パート内の画面遷移は「証言ブロック単位」**。ブロック開始ごとに自動保存する。
- **ゲームオーバーは章を破壊しない。** 解決パート冒頭または章冒頭からの再開を選べる。
- **章選択は解放済み章のみ**。章1は常に解放。
- 画面遷移はすべてフェード（0.3秒）。ローディング画面は作らない（全アセットを章単位で先読み）。

## 4. スキップとオート

| 機能 | 導入 | 調査 | 解決 | エピローグ |
| --- | --- | --- | --- | --- |
| テキスト送り | 手動 | 会話中のみ手動 | 手動 | 手動 |
| 既読スキップ | 可 | 可（会話のみ） | 不可 | 可 |
| オートモード | 可 | 会話中のみ可 | 不可 | 可 |

解決パートにオートを入れない理由: 誤答の責任をプレイヤーに帰属させるため。

## 5. 例外・エラー時

| 状況 | 挙動 |
| --- | --- |
| セーブデータ破損 | タイトルへ戻し、「データを初期化しました」を表示 |
| アセット読み込み失敗 | 該当章をロックし、章選択に注記を出す |
| 画面遷移中の入力 | 遷移完了まで入力を無視（二重遷移防止） |

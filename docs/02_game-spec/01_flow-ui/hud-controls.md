# HUD・操作仕様

## 1. 画面解像度

- 単一Canvas。世界は 320×180 の `worldCamera`（`zoom: 3`）、UIは 960×540 の `uiCamera`（`zoom: 1`）。
- HUD・文字・ボタンはすべてUIレイヤに描く（DOMは使わない）。**文字は24px以上**（スマホの小画面での可読性を優先）。
- 画面のピクセル粒は世界側のみ粗く、文字は等倍で保つ。

## 2. 調査パートのHUD

| 要素 | 位置 | 内容 |
| --- | --- | --- |
| 章タイトル | 左上 | 例「第一話 怒られたい少年」 |
| 現在地 | 左上（タイトル下） | 例「商店街・中央通り」 |
| 所持証拠 | 右上 | アイコン + 件数（`3/8`）。**タップで証拠一覧** |
| ヒント | 画面上部中央 | 次にやるべきこと1行。5秒表示で自動消灯 |
| 調べるプロンプト | 対象の上 | 近接時のみバルーンボタン「調べる」 |
| 会話ウィンドウ | 下部 | 話者名、本文、送りマーカー |
| 移動ボタン | 画面左下 | `◀` `▶`（押している間だけ移動） |
| 洞察トグル | 画面右下 | 目のアイコン。トグル式 |
| ポーズ | 右上端 | `≡` |

ヒントは常時表示しない。プレイヤーが30秒以上同一画面で操作なしの場合のみ再表示する。

## 3. 解決パートのHUD

| 要素 | 位置 | 内容 |
| --- | --- | --- |
| 証言者名 | 上部中央 | 例「郷田 権造」 |
| 証言ブロック | 中央 | 現在の証言文（1ブロック＝1〜3文） |
| 証言番号 | 証言ブロック左上 | `証言 2/4` |
| ミスカウント | 右上 | `○ ○ ○` → 誤答で `×` に置換 |
| 差し出しボタン | 下部左 | 押すと証拠一覧モーダル |
| 問い返しボタン | 下部中央 | 証言の詳細を掘る |
| 進行ログ | 画面外（内部） | 直近の証言・指摘を保持し、ポーズから閲覧可 |

ミスカウントは**残数ではなく累積**を表示する（`× × ○` は2ミス）。残数表示は行わない。

## 4. 入力の基本

| 項目 | 規定 |
| --- | --- |
| タッチファースト | すべての操作はタップで完結。キーボード・マウスは等価入力 |
| タップ判定 | UIオブジェクトは最小 **44×44px**（uiCamera座標）。世界側はホットスポットごと |
| 誤タップの抑制 | 押せるものだけ反応する。押せないボタンは灰色で非活性 |
| ドラッグ&ドロップ | 採用しない。差し出しは「証拠を選ぶ→即実行」 |
| ブラウザ抑制 | `touch-action: none`、ダブルタップズーム・スクロールを無効化 |

## 5. タッチ操作（パート別）

### 5.1 導入・エピローグ

| 操作 | 動作 |
| --- | --- |
| 本文タップ | 次のテキストへ送り |
| 送りマーカー `▼` | 同上 |
| `スキップ` ボタン（既読時のみ） | 既読をまとめて送る |

### 5.2 調査パート

| 操作 | 動作 |
| --- | --- |
| `◀` `▶` を押し続ける | その方向へ移動（指を離すと停止） |
| 対象の頭上のバルーンボタン `調べる` / `話す` | 近接時のみ出現。押すと実行 |
| 会話中の本文タップ | 次のテキストへ送り |
| 洞察トグル（目のアイコン） | 洞察視点の ON/OFF |
| 右上の証拠カウンター | 証拠一覧を開く |
| `≡` | ポーズメニュー |

- 移動中はバルーンボタンを非表示にする（押し間違い防止）。停止時に再表示。
- テキストウィンドウは**テキストがあるときだけ**表示する。移動を始めたら閉じる。
- 会話中は移動を止め、ウィンドウのタップで台詞を送る。最後の台詞で証拠を入手し、ウィンドウを閉じる。
- 調査パートで画面中央をタップしても何も起きない（対象のみが反応）。

### 5.3 解決パート（弁論）

| 操作 | 動作 |
| --- | --- |
| 証言本文タップ | テキスト送り。送り終わると操作ボタンが活性化 |
| `問い返し` | 現在の証言の詳細を掘る。リスクなし |
| `差し出す` | 証拠一覧モーダルを開く |
| 証拠一覧の証拠をタップ | **即実行**（確認なし）。正解なら進行、不正解ならミス+1 |
| `証拠一覧を閉じる` `×` | モーダルを閉じる（実行しない） |

- 証拠一覧のタイルは 48×48px 以上。証拠名はタイル下に1行表示。
- モーダル中は背景の押下を無視する。
- 「保留」（何も指摘しないで聞き直す）は、証言本文タップで再送りできる。

### 5.4 共通UI

| 操作 | 動作 |
| --- | --- |
| `≡` → ポーズメニュー | セーブ / 設定 / 章選択 / 続ける |
| 設定の各項目 | タップで値をサイクル（文字速度など） |
| 長押し | 使用しない（誤操作防止のため全廃） |

## 6. キーボード・マウス（等価入力）

| 操作 | キー / マウス |
| --- | --- |
| 移動 | ← → / A D |
| 決定・送り | Z / Enter / Space / クリック |
| キャンセル・戻る | X / Esc / 右クリック |
| 調べる・話す | C / 対象クリック |
| 証拠品一覧 | Tab / カウンタークリック |
| 問い返し（解決） | C / ボタンクリック |
| 差し出し（解決） | X / ボタンクリック→証拠クリック |
| ポーズ | Esc / `≡` クリック |

ホバーによるカーソル変化は行うが、操作はホバーに依存しない。

## 7. アクセシビリティ

| 項目 | 既定 | 変更 |
| --- | --- | --- |
| 文字速度 | 中 | 遅い／中／速い／即時 |
| 文字サイズ | 100% | 100 / 125 / 150%（UIレイヤのスケール） |
| 画面振動 | 有 | 無 |
| フラッシュ演出 | 有 | 無（白フラッシュをフェードに置換） |
| タッチ目標の拡大 | なし | あり（44px → 64px） |

設定はセーブデータとは別キーで保存する（章を跨いで維持）。

## 8. 表示文言

- すべて `src/localization/ja.json` を経由する。HUDの固定文言もハードコードしない。
- 1990年代の雰囲気を壊す記号（絵文字、半角カナの乱用）は使わない。
- 数字は全角・半角を統一する（本文は半角、金額は `¥300,000`）。

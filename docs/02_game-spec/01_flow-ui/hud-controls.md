# HUD・操作仕様

## 1. 画面解像度

- ゲーム世界の内部解像度: **320 × 180**（3倍拡大して 960 × 540 表示。`pixelArt: true`、`roundPixels: true`）。
- HUDは内部解像度ではなく**表示解像度（960×540）のDOM**で描画する。文字は12px以上。
- 画面のピクセル粒は世界側のみ粗く、文字は滑らかに保つ。

## 2. 調査パートのHUD

| 要素 | 位置 | 内容 |
| --- | --- | --- |
| 章タイトル | 左上 | 例「第一話 怒られたい少年」 |
| 現在地 | 左上（タイトル下） | 例「商店街・中央通り」 |
| 所持証拠 | 右上 | アイコン + 件数（`3/8`） |
| ヒント | 画面上部中央 | 次にやるべきこと1行。5秒表示で自動消灯 |
| 調べるプロンプト | 対象の上 | 近接時のみ `[C] 調べる` |
| 会話ウィンドウ | 下部 | 話者名、本文、送りマーカー |
| ポーズ | 右上端 | `≡` アイコン（タッチ時） |

ヒントは常時表示しない。プレイヤーが30秒以上同一画面で操作なしの場合のみ再表示する。

## 3. 解決パートのHUD

| 要素 | 位置 | 内容 |
| --- | --- | --- |
| 証言者名 | 上部中央 | 例「郷田 権造」 |
| 証言ブロック | 中央 | 現在の証言文（1ブロック＝1〜3文） |
| 証言番号 | 証言ブロック左上 | `証言 2/5` |
| ミスカウント | 右上 | `○ ○ ○` → 誤答で `×` に置換 |
| 証拠品ボタン | 下部左 | `[Tab] 証拠品` |
| 問い返しボタン | 下部中央 | `[C] 問い返し` |
| 差し出しボタン | 下部右 | `[X] 差し出し` |
| 進行ログ | 画面外（内部） | 直近の証言・指摘を保持し、ポーズから閲覧可 |

ミスカウントは**残数ではなく累積**を表示する（`× × ○` は2ミス）。残数表示は行わない。

## 4. 入力割り当て

### キーボード

| 操作 | キー |
| --- | --- |
| 移動 | ← → / A D |
| 決定・送り | Z / Enter / Space |
| キャンセル・戻る | X / Esc |
| 調べる・話す | C |
| 証拠品一覧 | Tab |
| 問い返し（解決） | C |
| 差し出し（解決） | X |
| ポーズ | Esc（長押しではなく単押し） |
| スキップ（既読） | Ctrl 長押し |

### マウス・タッチ

- タップ: 対象の調べる／決定。
- 画面下の仮想ボタン（左: 移動、右: 決定/戻る）はタッチ端末のみ表示。
- 証拠品のドラッグ&ドロップは**採用しない**。差し出しは「証拠を選ぶ→対象の証言を選ぶ」の2タップ。

## 5. アクセシビリティ

| 項目 | 既定 | 変更 |
| --- | --- | --- |
| 文字速度 | 中 | 遅い／中／速い／即時 |
| 文字サイズ | 100% | 100 / 125 / 150% |
| 画面振動 | 有 | 無 |
| フラッシュ演出 | 有 | 無（白フラッシュをフェードに置換） |
| ミスカウント警告音 | なし（音は実装しない） | なし |

設定はセーブデータとは別キーで保存する（章を跨いで維持）。

## 6. 表示文言

- すべて `src/localization/ja.json` を経由する。HUDの固定文言もハードコードしない。
- 1990年代の雰囲気を壊す記号（絵文字、半角カナの乱用）は使わない。
- 数字は全角・半角を統一する（本文は半角、金額は `¥300,000`）。

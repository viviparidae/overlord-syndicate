# ゲームループ・進行

## 1. 1章の流れ

```
導入 ──▶ 調査 ──▶ 解決 ──▶ エピローグ ──▶ 次章解放
             │                      ▲
             └── 証拠が揃う ────────┘
                    │
              解決パートでミス上限到達
                    ▼
              ゲームオーバー → リトライ
```

章の所要時間の目標は 15〜20 分。うち調査 6〜8 分、解決 5〜7 分、読み物 4〜5 分。

## 2. 導入パート

- 形式: ADV（背景 + 立ち絵128×160 + テキストウィンドウ）。文章はDOM側で描画する。
- 選択肢は**関係性の色付けのみ**。進行やフラグには影響しない（章1）。
- 役割: 事件の発覚、人物の提示、主人公の「表の顔」の提示。
- 章1では主人公の内面を開示しない（モノローグ禁止）。叙述規約は [[docs/04_lore/narrative-rules]]。
- 終了条件: 最後のテキスト送り。調査パート開始時に自動保存。

## 3. 調査パート

### 3.1 進行モデル

横スクロールの1ロケーション（商店街）を移動し、ホットスポットを調べる。
ホットスポットは種別を持つ。

| 種別 | 入力 | 結果 |
| --- | --- | --- |
| `inspect` | C | テキスト + 証拠入手（ある場合） |
| `talk` | C | 会話ツリー。初回のみ証言獲得 |
| `move` | C | 別エリアへ（画面遷移） |
| `locked` | C | 「今は必要ない」テキスト。条件を満たすと `inspect` に変わる |

### 3.2 解放条件

- エリアは章の進行度（入手証拠数）で解放する。**順序の自由度は確保**するが、行き止まりは作らない。
- 必須証拠が揃うと、中央通りの組合事務所前に「総会」マーカーが出現し、解決パートへ進める。
- 必須証拠が1つでも欠けている場合、マーカーは「まだ材料が足りない」と表示するだけ。不足分のヒントは出さない（探索の手応えを残す）。

### 3.3 失敗

- 調査パートに失敗は存在しない。誤った場所を調べてもテキストが返るだけ。
- 時間制限・回数制限は設けない。

## 4. 解決パート（弁論）

### 4.1 構造

1つの事件を、証言者ごとの「証言ブロック」の連なりとして提示する。

```
証言ブロック（証言者: 郷田）
  ├ 証言 1/5
  ├ 証言 2/5  ← ほころび（証拠: 防犯用VHS）
  ├ 証言 3/5
  ├ 証言 4/5  ← ほころび（証拠: 被害帳簿）
  └ 証言 5/5
```

- 各ブロックには**最大1つのほころび**が設定される。
- ほころびの数は章設定（章1は3箇所）。
- ほころびのない証言にも「問い返し」で追加情報が出る場合がある（任意）。

### 4.2 プレイヤーの行動

| 行動 | コスト | 結果 |
| --- | --- | --- |
| 問い返し | なし | 証言の詳細を掘る。追加テキスト。ほころび箇所では新たな証言が派生することがある |
| 差し出し（証拠選択） | 誤答でミス+1 | 正解なら進行、不正解なら反応テキスト + ミスカウント増加 |
| 証拠品閲覧 | なし | 詳細テキスト。閲覧はいつでも可 |
| 保留（何もしない） | なし | 証言を最後まで聞くと「指摘できなかった」として再提示。ミスは増えない |

「保留」で同じ証言を聞き直せるため、詰みは発生しない。ただしほころびを指摘しない限り先へ進めない。

### 4.3 判定

- 正解: 選んだ証拠IDが、その証言ブロックの `gap.evidenceId` と一致する。
- 一部の証言は `gap.acceptAnyOf: string[]` を持ち、複数正解を許容する。
- 不正解時は、その証拠に対応する「反応テキスト」を表示してから証言に戻る。

### 4.4 ミスカウントとゲームオーバー

| 項目 | 値 |
| --- | --- |
| 上限（章1） | 3 |
| 上限（章2以降） | 章設定で 2〜4 |
| リセット | 章開始時、およびゲームオーバーからのリトライ時 |
| セーブ | ミスカウントも保存する。再開時に引き継ぐ |

上限到達で即座にゲームオーバー画面へ遷移する。演出は0.8秒の暗転 + 弁論の静寂。

### 4.5 リトライ

ゲームオーバー画面で2択を提示する。

1. **解決パートの冒頭から**（推奨・既定）— ミスカウントを0に戻す。証拠は保持。
2. **章の最初から** — 導入からやり直す。調査パートの証拠も初期化。

「ミスカウントだけ戻して同じ証言から」は提供しない。誤答の重みを残すため。

## 5. エピローグ

- 形式: ADV。解決の結果を住人たちの反応で描く。
- **分岐は存在しない。** 結末は章ごとに1つに固定する。プレイヤーの選択が変えるのは到達の道筋のみ。
- 章末で次章のフックを1カットだけ見せる。

## 6. 章を跨ぐ進行

- 解放条件: 前章のエピローグ終了。章選択画面に進行度を表示。
- 持ち越し: 入手済み証拠のうち `persistent: true` のもの（章1では0件を想定）。
- 持ち越さない: ミスカウント、調査パートの位置、会話既読フラグ（章内のみ）。

## 7. 全体進行（4フェーズ）

| フェーズ | 舞台 | 章の目安 | 仲裁の相手 |
| --- | --- | --- | --- |
| 1 | シャッター商店街 | 第1〜3章 | 商店街の住人、地主 |
| 2 | 地方都市 | 第4〜6章 | 商店会連合、地方局 |
| 3 | 首都・国家 | 第7〜9章 | 業界団体、官僚 |
| 4 | グローバル | 第10〜12章 | 国家間の利権 |

プロトタイプ第二弾は**第1章のみ**を実装対象とする。

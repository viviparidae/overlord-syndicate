# 2Dスプライト・UI規格

## 1. 基本

| 項目 | 値 |
| --- | --- |
| 論理解像度 | 960 × 540 |
| ピクセルアート | 有効（`pixelArt: true`, `roundPixels: true`） |
| 描画倍率 | 整数倍（1x / 2x / 3x）。半端な拡大を禁止 |
| タイル基準 | 16 × 16 px |
| 背景パララックス | **2層**（遠景 / 中景）。手前はコード描画 |
| 色数 | 1アセットあたり最大32色。パレットは章共通 |

## 2. スプライト寸法

| 種別 | 寸法（px） | 備考 |
| --- | --- | --- |
| 主人公（調査） | 64 × 64 | フリー素材の規格に合わせる。1人1枚 |
| 住人（調査） | 64 × 64 | 主人公と同規格 |
| 立ち絵 | - | **廃止**。会話中はスプライトを2倍拡大（128×128） |
| 証拠アイコン | 48 × 48 | 64pxグリッドの中央配置 |
| 背景 | 960 × 540 | エリア単位。スクロールは端でつなぐ |
| UIパーツ | 8px グリッド | 9スライスの余白は 8px |

## 3. 配色

1990年代の地方都市。彩度を落とし、蛍光灯の白と夕景の橙を対比に使う。

| 用途 | 色 | メモ |
| --- | --- | --- |
| 基本背景 | `#2b2b33` | 夜の商店街 |
| アーケード灯 | `#e8d9a0` | 電灯の暖色 |
| 主人公の強調 | `#7f9bb3` | 冷たい青。感情を出さない |
| 住人 | `#c9a27a` | 暖色。生活感 |
| 敵対者 | `#8f5a5a` | 沈んだ赤 |
| 警告・ミス | `#d9525b` | ミスカウント、フラッシュ |
| テキスト | `#f2efe6` | 本文 |
| 補助線・枠 | `#4a4a55` | UIの枠 |

- グラデーションは2〜3段のディザで表現する。滑らかなグラデーションを使わない。
- 画面全体の平均輝度は落としすぎない（テキスト可読性のため）。

## 4. フォント

| 用途 | 規格 |
| --- | --- |
| 本文 | フリーの日本語ドットフォント（12px / 16px）。候補: PixelMplus 等 |
| 見出し | 同フォントの16px二重描き（太字ウェイトがなければ） |
| 欧文数字 | 等幅。金額表示に使用 |
| フォールバック | `Noto Sans JP`（Webフォント。読込失敗時のみ） |

- Webフォントの読込完了前にテキストを表示しない（レイアウトずれ防止）。
- 文字サイズ設定（100/125/150%）に応じて、DOMオーバーレイ側はCSSで拡大する。

## 5. UIパーツ

| パーツ | 規格 |
| --- | --- |
| テキストウィンドウ | 9スライス、枠 2px、背景 `#12121a` 90% |
| 証拠品スロット | 64 × 64、選択時は外枠を `#e8d9a0` に |
| ミスカウント印 | 16 × 16。`○`（未使用）/ `×`（累積） |
| ボタン | 高さ 32px、押下時は1px沈む |
| スクロールバー | 幅 4px、つまみ 8px 角 |

## 6. 書き出し

| 種別 | 形式 | 備考 |
| --- | --- | --- |
| 背景・スプライト | PNG-8（パレット） | 透過はアルファ1bit |
| UI | PNG（9スライス） | 拡大はコード側で行う |
| 音声 | OGG Vorbis | 詳細は [[docs/03_production/04_audio/audio-specs]] |

- 画像は**等倍**で書き出し、拡大はランタイムで行う。
- ファイルサイズ目標: 背景1枚 150KB 以下、スプライト1枚 20KB 以下。

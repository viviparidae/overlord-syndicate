# 2Dスプライト・UI規格

## 1. 基本

| 項目 | 値 |
| --- | --- |
| 内部解像度 | **320 × 180**（表示は3倍で 960 × 540） |
| 表示解像度 | 960 × 540 |
| ピクセルアート | 有効（`pixelArt: true`, `roundPixels: true`） |
| 描画倍率 | **3倍固定**（320×180 → 960×540）。半端な拡大を禁止 |
| タイル基準 | 8 × 8 px（内部解像度基準） |
| 背景パララックス | **2層**（遠景 / 中景）。手前はコード描画 |
| 色数 | 1アセットあたり最大**16色**。パレットは章共通 |

## 2. スプライト寸法

| 種別 | 寸法（px） | 備考 |
| --- | --- | --- |
| 主人公（調査） | 32 × 48 | 静止画1枚。表示は3倍（96×144） |
| 住人（調査） | 32 × 48 | 主人公と同規格 |
| 立ち絵 | 128 × 160 | 表示は3倍（384×480）。目は描かない |
| 顔伏せカット | 128 × 160 | 下向き1枚を全員で使い回す（任意） |
| 証拠アイコン | 16 × 16 | 表示は3倍（48×48） |
| 背景 | 320 × 180 | 表示は3倍。スクロールは端でつなぐ |
| UIパーツ | 4px グリッド | 9スライスの余白は 4px。文字はUIカメラ側に描画 |

## 3. 配色

1990年代の地方都市。彩度を落とし、蛍光灯の白と夕景の橙を対比に使う。
パレットは**16色**。以下は主要8色で、残り8色は中間色とディザ用に割り当てる。

| 用途 | 色 | メモ |
| --- | --- | --- |
| 基本背景 | `#2b2b33` | 夜の商店街 |
| アーケード灯 | `#e8d9a0` | 電灯の暖色 |
| 主人公の強調 | `#7f9bb3` | 冷たい青。感情を出さない |
| 住人 | `#c9a27a` | 暖色。生活感 |
| 敵対者 | `#8f5a5a` | 沈んだ赤 |
| 警告・ミス | `#d9525b` | ミスカウント、フラッシュ |
| テキスト | `#f2efe6` | 本文 |
| 補助線・枠 | `#4a4a55` | UIの枠 |
| 影（ディザ1） | `#1a1a20` | 暗部の市松 |
| 影（ディザ2） | `#0d0d10` | 最も暗い段 |

- グラデーションは2〜3段のディザ（市松・網点）で表現する。滑らかなグラデーションを使わない。
- 暗部は黒に潰す。中間色を増やさない（PS1の15bit色の感覚）。
- 画面全体の平均輝度は落としすぎない（テキスト可読性のため）。

## 4. フォント

| 用途 | 規格 |
| --- | --- |
| 本文 | ビットマップフォント（`.fnt` + PNG）をUIカメラに描く。フリーの日本語ドットフォントを変換して使う |
| 見出し | 同フォントの16px二重描き（太字ウェイトがなければ） |
| 欧文数字 | 等幅。金額表示に使用 |
| フォールバック | `Noto Sans JP`（Webフォント。読込失敗時のみ） |

- Webフォントの読込完了前にテキストを表示しない（レイアウトずれ防止）。
- 文字サイズ設定（100/125/150%）はUIレイヤのスケールで実現する（ビットマップフォントを等倍のまま拡大）。

## 5. UIパーツ

| パーツ | 規格 |
| --- | --- |
| テキストウィンドウ | 9スライス、枠 2px、背景 `#12121a` 90% |
| 証拠品スロット | 64 × 64、選択時は外枠を `#e8d9a0` に |
| ミスカウント印 | 16 × 16。`○`（未使用）/ `×`（累積） |
| ボタン | 高さ 32px、押下時は1px沈む |
| スクロールバー | 幅 4px、つまみ 8px 角 |

## 6. 書き出し

| 種別 | 形式 | 備考 |
| --- | --- | --- |
| 背景・スプライト | PNG-8（16色パレット） | 透過はアルファ1bit |
| UI | PNG（9スライス） | 拡大はコード側で行う |
| 音声 | OGG Vorbis | 詳細は [[docs/03_production/04_audio/audio-specs]] |

- 画像は**等倍**で書き出し、拡大はランタイムで行う。
- ファイルサイズ目標: 背景1枚 60KB 以下、スプライト1枚 8KB 以下、立ち絵1枚 30KB 以下。

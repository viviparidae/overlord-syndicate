# アニメーション・ステート

作画リソースがないため、**フレームアニメーションは行わない**。
スプライトは静止画1枚とし、状態は変換（位置・回転・拡大率・透明度）で表現する。

## 1. 共通パラメータ

| 状態 | 変換 | 周期 | 用途 |
| --- | --- | --- | --- |
| `idle` | 縦 ±1px | 2.4s | 待機 |
| `walk` | 縦 ±2px、傾き ±2° | 0.5s | 移動中。速度に比例 |
| `talk` | 拡大 1.00→1.01 | 0.8s | 台詞表示中 |
| `listen` | 縦 +1px（固定） | - | 相手の台詞中 |
| `inspect` | 前傾（傾き 4°、0.2s）→ 戻る | 1回 | 調べる |
| `insight` | 彩度↓（ティント）、縦 ±0.5px | 3s | 洞察視点 |
| `surprise` | 縦 -3px、拡大 1.03 | 1回（0.3s） | 驚き |

- 変換の基準点は足元（`originY = 1.0`）。拡縮で接地が浮かないようにする。
- 左右の向きは `flipX` で表現する。左向き専用の画像は作らない。

## 2. 解決パート

| 状態 | 表現 |
| --- | --- |
| `stand` | 静止（idle相当） |
| `talk` | 拡大 1.01 の往復 |
| `sweat` | 縦 ±1px を速く（0.3s）、彩度↓ |
| `break` | 傾き -6° → 0°、拡大 1.05 → 1.00（0.6s） |
| `smug` | 傾き +3° で固定 |

- 表情は**画像差し替え**（AI生成の差分）で切り替える。差分がない人物は変換のみ。
- カメラは固定。揺らさない。

## 3. 画面演出（コード）

| 演出 | 実装方針 | 時間 |
| --- | --- | --- |
| つきつけ成功 | 白フラッシュ（1フレーム）＋証拠アイコンを中央へ拡大 | 1.2s |
| つきつけ失敗 | 赤フラッシュ（設定で無効化可）＋画面を1px揺らす | 0.9s |
| ミス上限到達 | 暗転 | 0.8s |
| 追及 | 証言ウィンドウの明滅（不透明度 1.0→0.7） | 0.3s |
| 証拠入手 | アイコンが右上へ移動（トゥイーン） | 0.6s |
| エリア移動 | フェード | 0.3s |

画像素材は追加しない。矩形・円・グラデーション（コード）と既存スプライトの変形のみで構成する。

## 4. テキスト送り

| モード | 1文字あたり |
| --- | --- |
| 遅い | 60ms |
| 中 | 30ms |
| 速い | 12ms |
| 即時 | 0ms |

句読点 120ms、`！` `？` 200ms、三点リーダ 300ms。

## 5. 制約

- 1フレーム内でオブジェクトを生成しない。トゥイーンは状態遷移時に開始する。
- 変換の数値は `src/balance/` の定数表で管理し、コードに直書きしない。
- 60fps を目標。処理落ち時は演出を間引く（進行は止めない）。

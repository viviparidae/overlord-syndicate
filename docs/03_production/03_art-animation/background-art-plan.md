# 背景制作プラン

第1章の背景のみを対象とする。実装・作画はまだ行わない。

## 1. 仕様

| 項目 | 値 |
| --- | --- |
| 論理解像度 | 960 × 540 |
| エリア数 | 4（`arcade_west` / `arcade_center` / `arcade_east` / `shotengai_office`） |
| レイヤ | 3層（遠景 / 中景 / 手前） |
| パララックス速度 | 遠景 0.2倍 / 中景 0.5倍 / 手前 1.0倍（プレイヤーと同速） |
| スクロール | 横1方向。エリア端で次エリアへ接続（ロードなし） |
| 時間帯 | 夕方（導入・調査）／夜（解決）の2バリエーション |
| 色数 | 1レイヤ32色以内。共通パレットを使用 |
| 形式 | PNG-8、透過は前景のみ |

## 2. 画面構成

| レイヤ | 内容 | スクロール | 備考 |
| --- | --- | --- | --- |
| 遠景 | 空、遠くの建物、山並み、電柱の列 | 0.2 | 空はグラデ禁止。3段ディザ |
| 中景 | アーケード、店構え、シャッター、看板の枠 | 0.5 | 店名は焼き込まない |
| 手前 | 自転車、植栽、電柱、幟、落下物 | 1.0 | キャラクターの前後関係を作る |

- 手前レイヤは**キャラクターより手前に描く小物**と**足元の接地物**に分ける。接地物は中景に置く。
- キャラクターが立つラインは画面下から 96px（y=444）。この線より上に障害物を置かない。
- 空や壁の面積が大きいので、テクスチャ（タイルの継ぎ目、雨染み）で単調さを避ける。

## 4. 制作手順（AI生成前提）

1. **レイアウトラフ**: 紙または矩形で、建物の並びとホットスポット位置を確定する。
2. **生成**: レイヤごとに個別に生成する。プロンプトに「no characters, no text, side view, 1990s Japanese shopping street」を含める。
3. **選定**: 1レイヤ3案。構図が座標表と合うものを選ぶ。
4. **縮小とドット化**: 長辺 1920px で生成 → 960×540 に縮小 → パレット量子化（32色）→ 輪郭と粒を手で整える。
5. **継ぎ目処理**: エリア端は左右で色と形を合わせる。ループ用に端 64px を複製して加工する。
6. **夜差分**: 夕方版の色を落とし、光源（アーケード灯、店の窓）を追加する。再生成せず色調で作る。
7. **当て込み**: 仮キャラを配置し、コントラストと接地を確認する。

### 4.1 生成時の禁止

- 看板・貼り紙の文字を焼き込む（文字は別レイヤのオーバーレイで描く）。
- 人物・動物を入れる（キャラクターと衝突する）。
- 実在の店名・ロゴ・チェーン店を含める。
- 現代的な要素（LED、スマホ、自販機の新型）を入れる。

## 5. 工数見積

| 項目 | 手描き | AI生成＋補正 |
| --- | --- | --- |
| 1エリア（3層） | 10h | 4h |
| 4エリア | 40h | 16h |
| 夜差分（4エリア） | 8h | 4h |
| 継ぎ目・当て込み調整 | 6h | 6h |
| **合計** | **54h** | **26h** |

- 第1章の縦切り（Tier 1）では `arcade_center` と `shotengai_office` の2エリアのみ制作する（AI時 約8h＋調整）。
- 背景はキャラクターより先に「画面の基準露出」を決める役割があるため、段階A（スタイル確立）で1面だけ先に作る。

## 6. 受け入れ基準

| 観点 | 基準 |
| --- | --- |
| 文字 | 背景画像に文字が焼き込まれていない |
| 継ぎ目 | エリア端で色・形が連続する。1xで線が見えない |
| パララックス | 3層の速度差で破綻しない（遠景が手前を追い越さない） |
| 可読性 | キャラクターのシルエットが背景に埋もれない |
| ホットスポット | 座標表の範囲に対象物が存在し、1段の明度差がある |
| 時代考証 | 1997年より後の要素がない |
| パレット | 32色以内。共通パレット外の色を使わない |

## 7. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| AI生成のレイヤ分離ができない | パララックスが成立しない | レイヤを個別生成する。1枚絵からの分離は行わない |
| 継ぎ目の破綻 | スクロールで目立つ | 端64pxの複製加工を必須工程にする |
| 文字の焼き込み | ローカライズ不能・可読性低下 | 生成禁止事項に明記。看板は別レイヤ |
| 画風の混在 | 画面の統一感が崩れる | 共通パレットと段階Aの見本に合わせる |
| 工数圧迫 | キャラクター制作が遅れる | Tier 1は2エリアに限定 |

# 背景制作プラン

前提: 作画できる人はいない（[[docs/03_production/01_conventions/asset-sourcing-policy]]）。
第1章の背景のみを対象とする。

## 1. 仕様

| 項目 | 値 |
| --- | --- |
| 内部解像度 | **320 × 180**（表示は3倍で 960 × 540） |
| エリア数 | 4（`arcade_west` / `arcade_center` / `arcade_east` / `shotengai_office`） |
| レイヤ | **2層**（遠景 / 中景） |
| パララックス速度 | 遠景 0.3倍 / 中景 1.0倍 |
| スクロール | 横1方向。エリア端で接続（ロードなし） |
| 時間帯 | 夕方のみ生成。夜はエンジンのティントで代用 |
| 色数 | 1レイヤ16色以内（自動減色・ディザあり） |
| 形式 | PNG（不透明）。透過レイヤなし |

### 1.1 削ったもの

- **手前レイヤ**: 作らない。電柱・自転車などの手前要素はコードで単色シルエットを描く。
- **夜差分の作画**: 行わない。夕方版に色調変換（暗色化＋青寄せ）をかける。
- **看板の文字**: 焼き込まない。すべてコードでテキスト描画する。
- **3層パララックス**: AIで層を分離するコストが高いため2層に削減。

## 2. 画面構成

| レイヤ | 内容 | スクロール | 備考 |
| --- | --- | --- | --- |
| 遠景 | 空、遠くの建物、山並み | 0.3 | 空は単色＋ディザ（生成後に減色） |
| 中景 | アーケード、店構え、シャッター、掲示板 | 1.0 | ホットスポットはここに描かれる |
| 手前（コード） | 電柱、自転車、植栽のシルエット | 1.0 | 矩形・多角形で描画。画像なし |

- キャラクターの接地ラインは画面下から 96px（y=444）。
- 中景のみが実質的な背景。遠景は「奥行きの記号」として扱う。

- 光る演出は付けない。

## 4. 手順

1. **生成**: 遠景と中景を別々に生成。プロンプトに「no characters, no text, no signage letters, side view, 1990s Japanese shopping street」を含める。
2. **選定**: 1レイヤ3案。
3. **縮小・減色**: 1280×720 で生成 → **320×180** に縮小 → 16色へ量子化（ディザあり）。
4. **継ぎ目**: 端64pxを複製して反転合成（自動）。線が出る場合は端をぼかしてごまかす。
5. **夜**: 夕方版にティント（乗算で暗色化）を適用。専用画像は作らない。
6. **当て込み**: 仮キャラを置き、コントラストと接地を確認する。

### 4.1 生成時の禁止

- 看板・貼り紙の文字（読める文字を焼き込ませない）。
- 人物・動物。
- 実在の店名・ロゴ・チェーン店。
- 現代的な要素（LED、スマホ、新しい自販機）。

## 5. 工数見積

| 項目 | 工数 |
| --- | --- |
| 遠景・中景の生成（4エリア × 2層、3案ずつ） | 8h |
| 自動処理（縮小・減色・継ぎ目） | 2h |
| 検収・再生成 | 3h |
| **合計** | **約13時間** |

- Tier 1（`arcade_center` と `shotengai_office`）は約4h。
- 背景はキャラクターより先に1面作り、画面の明度基準を決める。

## 5.1 フリー素材の扱い

- パララックス背景のフリー素材（CC0）は洋風の作風が多く、本作の題材に合わない。**原則として使わない**。
- 使う場合は中景の一部（塀、道路）に限定し、生成物と同じ画面に混ぜない。

## 6. 受け入れ基準

| 観点 | 基準 |
| --- | --- |
| 文字 | 背景画像に文字が焼き込まれていない |
| 継ぎ目 | エリア端で色が連続する（線が見えない） |
| 可読性 | キャラクターのシルエットが背景に埋もれない |
| ホットスポット | 座標表の範囲に対象物があり、明度差が付いている |
| 時代考証 | 1997年より後の要素がない |
| 色数 | 16色以内（自動減色・ディザの結果で可） |

## 7. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| レイヤ分離の失敗 | パララックスが成立しない | レイヤを個別生成する。1枚絵からの分離はしない |
| 継ぎ目の破綻 | スクロールで目立つ | 端64pxの自動処理。目立つ場合のみ再生成 |
| 文字の焼き込み | ローカライズ不能 | 生成禁止事項に明記。看板はコード描画 |
| 画風の混在 | 統一感の崩れ | 同一モデル・共通パレット。段階Aの見本に合わせる |

## 8. 未決事項

- 生成モデル（キャラクターと共通か、背景専用か）
- 遠景を生成するか、単色＋コード描画で済ませるか（後者の方が速い）
- エリア端の接続方法（同一画像の使い回しか、専用のつなぎ画像か）

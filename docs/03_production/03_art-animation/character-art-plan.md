# キャラクターグラフィック制作プラン

前提: 作画できる人はいない。**キャラクターはフリー素材のみ**で構成する（[[docs/03_production/01_conventions/asset-sourcing-policy]]）。
AI生成は背景に限定し、人物には使わない（画風の統一を優先するため）。

## 1. 方針

1. **1パックから全員を作る**: 人物は1つの素材パックに統一する。複数パックの混在を禁止。
2. **差別化は色・大きさ・小物**: 色替え（スクリプト）、拡大率、帽子・眼鏡などの付属レイヤで8人を描き分ける。
3. **立ち絵は廃止**: 会話中は**スプライトを2倍拡大**して表示する。バストアップ素材は探さない。
4. **フレームは素材にあるものを使う**: 歩行アニメが同梱されていればそのまま使う（作業ゼロ）。なければトランスフォームで代用。
5. **ライセンス優先度**: CC0 > CC-BY > CC-BY-SA。**非商用（NC）と改変禁止（ND）は不可**。

## 2. 素材の選定基準

| 条件 | 基準 |
| --- | --- |
| ライセンス | CC0 / CC-BY / CC-BY-SA のいずれか。商用利用可。NC・ND は不可 |
| 題材 | 現代（1990年代風）の市街地に置ける服装。鎧・剣・ファンタジー衣装は不可 |
| 向き | 横視点（side view）。左右反転で両方向を賄えること |
| サイズ | 64×64 前後。32×32 でも拡大して使う |
| 構成 | 体・髪・服がレイヤ分離、または色替えが容易 |
| 人数 | 老若男女を同一画風で揃えられること |
| 形式 | PNG（透過）。スプライトシート可 |

### 2.1 候補（ライセンス確認は導入時に必須）

| 候補 | ライセンス | 長所 | 短所 |
| --- | --- | --- | --- |
| LPC / Universal LPC Spritesheet | CC-BY-SA 3.0 / GPL | 服・髪のレイヤが豊富。歩行アニメ同梱 | 中世寄り。現代服は派生セット頼み。SA継承 |
| OpenGameArt の CC0 人物セット | CC0 | 制約が緩い | 画風・服装の統一が難しい。日本語題材はほぼ無い |
| itch.io の無料人物パック | パックごとに異なる | 現代服が多い | 無料枠は少なく、shopkeeper系は有料（$2〜）が中心 |

- 1990年代日本の商店街に一致するフリーセットは**存在しない**前提で計画する。一致しなくても「現代の市街地」として成立すれば採用する。
- 有料パックは「フリー素材でできないことはやらない」の例外として**購入しない**。無料で揃わなければ立ち絵廃止・色替えで対応する。

| 人物 | 元素材 | 色 | 拡大率 | 小物・備考 |

| 郷田 航（14） | 細身体型 | 灰・青 | 0.85 | 小柄。学生服風の配色 |
| 松谷 静江（58） | 女性・標準 | 紫・白 | 0.95 | エプロン |
| 榎本 千夏（24） | 女性・細身 | 橙・白 | 1.00 | カメラは省略可 |
| 岡田 修（19） | 標準体型 | 作業着の青 | 1.00 | |
| 辰巳 徳造（68） | がっしり体型 | 灰・藍 | 1.00 | 帽子 |
| 丸福 健太（22） | 標準体型 | 白・水色 | 1.00 | 前掛け |

- 元素材が足りない場合、**性別・年齢の一致より「色と体格の差」を優先**する。全員が同一画風であることを優先する。
- 表情差分は作らない。感情は台詞とトランスフォーム（傾き・拡大）で表現する。

## 4. 作業手順

| 工程 | 手段 | 内容 |
| --- | --- | --- |
| 1. 選定 | 目視 | 1パックを選ぶ。ライセンスとクレジット条件を確認 |
| 2. 切り出し | スクリプト | スプライトシートから必要なフレームを切り出す |
| 3. 色替え | スクリプト | パレット差し替えで人物ごとの配色を作る |
| 4. 体格差 | 設定 | 0.85〜1.05 の範囲で拡大率を変える（非整数倍は許容） |
| 5. 命名 | 命名規則 | `char_{id}.png`（フレームがある場合は `char_{id}_walk_{n}.png`） |
| 6. 記録 | 台帳 | [[docs/asset-licenses]] にパック名・URL・ライセンス・クレジットを記録 |

- 色替えは共通パレットへの置換で行う。パレットは `assets-src/palette/` に置く（予定）。
- 素材の改変が禁止されている場合は色替えをせず、拡大率と小物だけで差別化する。

## 5. 工数見積

| 項目 | 工数 |
| --- | --- |
| パック選定・ライセンス確認 | 2h |
| 切り出し・色替えスクリプトの用意 | 2h |
| 8人の色・拡大率の調整 | 3h |
| 小物の取捨選択 | 1h |
| 検収（64×64での判別、背景との馴染み） | 2h |
| **合計** | **約10時間** |

- Tier 1（涼・郷田・航＋航の小柄化）は約4h。
- 立ち絵を廃止したため、前回計画（21h）からさらに半分。

## 6. スコープ

| ティア | 内容 | 工数 |
| --- | --- | --- |
| **Tier 1: 縦切り** | 素材選定、主要3人の色替え、UI枠、証拠アイコン | 約5h |
| **Tier 2: 章完成** | 残り5人の色替え、小物調整 | 約3h |
| **Tier 3: 調整** | 画風の馴染ませ、縮小確認 | 約2h |

## 7. 受け入れ基準

| 観点 | 基準 |
| --- | --- |
| ライセンス | 商用利用可。クレジット要否を記録済み。NC/ND でない |
| 統一感 | 8人が同一パック（同一画風） |
| 判別 | 64×64で誰が誰か判別できる（色・体格・小物） |
| 画風 | 背景（AI生成）と並べて破綻しない。破綻する場合は減色で寄せる |
| 透過 | 縁の白残りがない |
| 命名 | 規約どおり |

## 8. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 題材に合う無料素材がない | 画風が浮く | 「現代の市街地」として許容。最悪はAI生成スプライトに戻す |
| CC-BY-SA の継承義務 | アート部分の同一ライセンス公開が必要 | CC0/CC-BY を優先。SA採用時はクレジットとライセンスを明記 |
| 8人分の体格・年齢が揃わない | 14歳が大人に見える等 | 拡大率と配色で補正。台詞で補う |
| 背景（AI）と画風が合わない | 画面の統一感が崩れる | 共通パレットへ減色。必要なら背景側を調整 |
| 有料素材への誘惑 | 方針違反 | 予算0を維持。有料は使わない |

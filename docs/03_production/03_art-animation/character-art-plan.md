# キャラクターグラフィック制作プラン

本ドキュメントは制作計画であり、実装・作画はまだ行わない。
寸法・フレーム数は [[docs/03_production/03_art-animation/2d-art-standards]] と
[[docs/03_production/03_art-animation/animations]] を正とする。

## 1. 方針

1. **グレーボックス先行**: 仮スプライト（単色シルエット）でゲームループを成立させ、後から差し替える。
2. **主要3人に集中**: 第1章の仲裁を成立させる涼・郷田・航に工数を寄せる。他は簡易版で成立させる。
3. **立ち絵は1枚の精度を優先**: 表情差分は眉・口・目の3点のみ差し替えで作る。
- 手描きを原則とする。AI生成は構図検討のラフに限定し、最終アセットには使わない（パレット統一とアニメ一貫性のため）。

## 3. 制作の順序

| 段階 | 内容 | 目的 |
| --- | --- | --- |
| A. スタイル確立 | 涼の正面・横向き、パレット確定、1枚の見本 | 以後の品質基準を固定する |
| B. 主要3人 | 涼・郷田・航のスプライトと立ち絵3表情 | 第1章の仲裁が「本物の絵」で成立する |
| C. 背景2面 | 中央通り＋組合事務所の2面（各3層） | 画面の基準露出を確認 |
| D. 残りの人物 | 立ち絵と簡易スプライト | 章の全シーンを埋める |
| E. 小物・UI | 証拠アイコン、ミス印、証拠スロット | 解決パートの可読性を担保 |
| F. 仕上げ | アニメーションのタメ・間、表情差分の追加 | 手触りの調整 |

**並行作業の原則**: 背景とキャラクターは別担当に分ける。キャラクターは「スプライト → 立ち絵」の順（立ち絵の方が修正コストが高い）。

## 4. 工数見積

| 項目 | 単価（時間） | 数量 | 小計 |
| --- | --- | --- | --- |
| フルセット（27フレーム前後） | 18h | 3 | 54h |
| 簡易セット（16フレーム前後） | 9h | 2 | 18h |
| 静止セット（5フレーム） | 3h | 3 | 9h |
| 立ち絵（1体目・ベース込み） | 8h | 8 | 64h |
| 立ち絵の表情差分 | 2h | 9 | 18h |
| 証拠アイコン | 1.5h | 9 | 13.5h |
| UI・エフェクト素材 | - | - | 16h |
| **合計** | | | **約193時間** |

- 週10時間の作業で **約19週（約4.5ヶ月）**。週20時間なら約10週。Tier 3 まで含めると約22週。
- 立ち絵（82h）が最大の山。ここを外注に出すかが全体日程を左右する。
- 背景（4面 × 3層、約40h）は別枠。本ドキュメントはキャラクターのみを対象とする。

## 5. スコープの段階設定

| ティア | 内容 | 追加工数 | 完成時の状態 |
| --- | --- | --- | --- |
| **Tier 1: 縦切り** | 涼・郷田・航のスプライト＋立ち絵3表情、証拠アイコン9、UI一式（背景2面は別枠20h） | 約120h | 第1章の仲裁まで本物の絵で通しで遊べる |
| **Tier 2: 章完成** | 残り5人の簡易/静止スプライトと立ち絵8枚、背景4面 | 約73h | 第1章が全シーン埋まる |
| **Tier 3: 仕上げ** | アニメ拡張、表情追加、小物挿絵 | 約30h | 配布可能な品質 |

プロトタイプの意思決定用には **Tier 1** を先に完成させる。Tier 2 以降は手応えを見て判断する。

## 6. ツールとパイプライン

| 工程 | ツール | 出力 |
| --- | --- | --- |
| 作画 | Aseprite（`.aseprite` を原本として保持） | PNG-8 |
| パレット管理 | 共通パレットファイル（32色） | `.gpl` / Aseprite パレット |
| 背景 | Aseprite / Photoshop（ドット等倍） | PNG-8（3層） |
| 書き出し | Aseprite CLI で一括書き出し | `public/assets/characters/` |
| 確認 | 1x / 2x / 3x の拡大表示、シルエットテスト | - |

- 原本（`.aseprite`）は `assets-src/` に置き、ビルド対象に含めない。
- 書き出し名は [[docs/03_production/01_conventions/naming-conventions]] に従う。
- 1アセットにつき1ファイル。レイヤー統合済みのPNGのみを `public/` に置く。

## 7. 受け入れ基準（Definition of Done）

| 観点 | 基準 |
| --- | --- |
| パレット | 32色以内。共通パレット外の色を使わない |
| 輪郭 | 1px。アンチエイリアス禁止。透過はアルファ1bit |
| 光源 | 左上固定。影の方向を全キャラで統一 |
| シルエット | 黒で塗り潰しても誰か判別できる |
| 縮小耐性 | 1x で顔のパーツが潰れない。3x でドットが汚れない |
| アニメ | ループの継ぎ目で位置がずれない。歩行で足が滑らない |
| 命名 | 規約どおり。`_new` / `_final` を使わない |
| ライセンス | 外注・外部素材は `docs/asset-licenses.md`（予定）に記録 |

## 8. 外注・AI の方針

| 手段 | 用途 | 判断 |
| --- | --- | --- |
| 自作 | スプライト、UI、小物 | 基本。修正の速さが利点 |
| 外注（イラストレーター） | 立ち絵17枚 | 任意。納品仕様（寸法・パレット・レイヤー）を明記する |
| 外注（ドット絵師） | 主要3人のフルセット | 任意。アニメ指定書が必要 |
| 生成AI | 構図・ポーズのラフ検討のみ | 最終アセットには使用しない |

外注時の契約事項: 著作権の譲渡、二次利用（PV・配信）の許諾、修正回数、納品形式（`.aseprite` + PNG）。

## 9. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 立ち絵の工数超過 | 全体日程が崩れる | Tier 1 では3人に限定。残りはシルエットで仮置き |
| パレットの揺れ | 画面の統一感が崩れる | スタイル確立（段階A）でパレットを固定し、以後変更しない |
| アニメの工数増 | スプライト制作が膨らむ | 状態を7→5に削る判断を段階Bで行う |
| 外注の品質差 | キャラの描き分けが崩れる | 1体目で必ずテスト発注し、基準を共有する |
| 権利処理の漏れ | 配布不可 | 受領時にライセンス記録を必須にする |

## 10. 未決事項

- 制作主体: 全自作 / 立ち絵のみ外注 / 主要3人を外注（推奨: 立ち絵のみ外注）
- 立ち絵の画面占有率: 全身（400×480）か、バストアップ（400×300）か
- 予算上限と発注先の候補
- 背景を本ドキュメントの範囲に含めるか（現状は別枠）

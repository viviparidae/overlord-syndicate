# キャラクターグラフィック制作プラン

前提: **作画できる人はいない**。[[docs/03_production/01_conventions/asset-sourcing-policy]] に従い、
AI生成・フリー素材・コード描画のみで成立させる。手作業の補正は行わない。

## 1. 方針

1. **1キャラ1枚**: 調査スプライトは静止画1枚（右向き）。左向きは反転。
2. **動きはコード**: 歩行・待機・会話は画像を差し替えず、位置・傾き・拡縮で表現する（[[docs/03_production/03_art-animation/animations]]）。
3. **立ち絵はバストアップ**: 400×300。表情はAI再生成で作り、手描きの差分は行わない。
4. **自動処理のみ**: 生成物は減色・透過・リサイズのスクリプト処理だけを通す。
5. **主要3人に表情を寄せる**: 涼・郷田・航のみ表情差分を持つ。他は1枚。

## 3. 制作順序

| 段階 | 内容 | 目的 |
| --- | --- | --- |
| A. 基準確立 | 涼の立ち絵1枚とスプライト1枚を生成し、パレットと後処理を確定 | 以後の全生成の基準にする |
| B. 主要3人 | 涼・郷田・航の立ち絵（計9枚）とスプライト3枚 | 第1章の仲裁が成立する |
| C. 残り5人 | スプライト5枚、立ち絵6枚 | 全シーンが埋まる |
| D. 周辺 | 証拠アイコン9、UI枠1 | 解決パートが読める |
| E. 調整 | 減色結果の確認、トリミング、拡大表示での破綻チェック | 品質の底上げ |

## 4. 工数見積

| 項目 | 単価 | 数量 | 小計 |
| --- | --- | --- | --- |
| 立ち絵（3案生成＋自動処理＋選定） | 0.5h | 15 | 7.5h |
| スプライト（3案生成＋自動処理＋選定） | 0.4h | 8 | 3.2h |
| 証拠アイコンの選定・減色 | - | 9 | 1.5h |
| UI枠の生成と9スライス化 | - | 1 | 2h |
| 確認・差し替え（全体の50%を見込む） | - | - | 7h |
| **合計** | | | **約21時間** |

- 週10時間で **約2〜3週**。Tier 2 まで含めても1ヶ月弱。
- プロンプト調整は段階Aに集中させる。基準を満たさない案は捨てる。

## 5. スコープの段階設定

| ティア | 内容 | 工数 |
| --- | --- | --- |
| **Tier 1: 縦切り** | 涼・郷田・航の立ち絵9枚とスプライト3枚、証拠アイコン9、UI枠 | 約13h |
| **Tier 2: 章完成** | 残り5人のスプライトと立ち絵6枚 | 約8h |
| **Tier 3: 調整** | 破綻箇所の再生成、減色の詰め | 約5h |

手描き基準（168h）から**約8分の1**。Tier 1 は1〜2日で終わる想定。

## 6. パイプライン

| 工程 | 手段 | 内容 |
| --- | --- | --- |
| 1. 基準画像 | AI生成 | 涼の正面バストアップを3案。1案を採用し、以後の参照画像にする |
| 2. 生成 | AI生成 | 同一モデル・同一スタイル指定。3案ずつ |
| 3. 背景除去 | スクリプト | 単色背景で生成し、アルファを自動除去 |
| 4. 減色 | スクリプト | 32色パレットへ量子化 |
| 5. リサイズ | スクリプト | 400×300 / 32×48 へ縮小（最近傍） |
| 6. 検収 | 目視 | シルエット判別、破綻（指・文字）の有無 |
| 7. 配置 | 命名規則 | `char_{id}.png` / `face_{id}_{emotion}.png` |

- プロンプトには「1990s Japanese, pixel art, side view, transparent background, no text」を含める。
- 手・指は構図（ポケット、後ろ手、トリミング）で回避する。

## 7. 受け入れ基準

| 観点 | 基準 |
| --- | --- |
| 同一性 | 同じ人物の別表情が、同一人物に見える |
| シルエット | 32×48に縮小しても誰か判別できる |
| 破綻 | 指・文字・余計なオブジェクトが画面内にない |
| 色数 | 32色以内（自動減色の結果で可） |
| 透過 | アルファが正しく抜けている（縁の白残りがない） |
| 権利 | 生成モデルの規約が商用利用可。生成日とモデル名を記録 |

手描き前提の基準（1px輪郭の再描画、光源の統一、ループの継ぎ目）は **適用しない**。

## 8. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 同一性の崩れ | 別人に見える | 基準画像＋参照生成。崩れたら表情を減らす |
| 縮小で潰れる | 誰か分からない | シルエット優先の構図。32×48で確認して再生成 |
| 生成物の権利 | 公開停止 | モデル規約の確認と生成記録 |
| 時間の溶融 | プロンプト調整で終わる | 段階Aで基準を決め、以後は3案で打ち切る |

## 9. 未決事項

- 生成モデル（ローカル/API）と商用条件
- 立ち絵の背景（無地か、薄い商店街のぼかしを入れるか）
- 表情を15枚からさらに減らすか（Tier 1は9枚）

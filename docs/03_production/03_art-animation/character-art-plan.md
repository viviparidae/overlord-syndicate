# キャラクターグラフィック制作プラン

前提: 作画できる人はいない。**キャラクターはAI生成**で作る（[[docs/03_production/01_conventions/asset-sourcing-policy]]）。
画風は **1998年前後のPS1ゲーム（メタルギアソリッド風）**。粗いドット、低彩度、目を描かない。

## 1. スタイル定義

| 項目 | 規格 |
| --- | --- |
| 参照 | 『メタルギアソリッド』(1998) の低解像度モデル／テクスチャ |
| 内部解像度 | 320 × 180（表示は3倍で 960 × 540） |
| 立ち絵 | 128 × 160（表示 384 × 480） |
| スプライト | 32 × 48（表示 96 × 144） |
| 色数 | **16色**（1アセットあたり。共通パレット） |
| 陰影 | ディザ（市松・網点）で2〜3段。滑らかなグラデーション禁止 |
| 輪郭 | 暗色の1px。アンチエイリアス禁止 |
| 目 | 描かないのが理想。生成結果に目があっても**潰さず採用してよい** |
| 表情 | 眉・口の位置のみで表現。目での演技をしない |
| 質感 | テクスチャの粒、走査線的なノイズは任意（やりすぎない） |
| 彩度 | 低い。暗部は黒に潰す。光源は左上固定 |

### 1.1 目を省く方針（任意）

- PS1期のモデルは顔の解像度が足りず、目が「暗い穴」として潰れていた。
- AI生成で破綻しやすい目と指はプロンプト側で誘導する。目が描かれた場合はそのまま採用し、強制修正しない。
- 表情の情報量を落とすことで、叙述規約（感情を説明しない）と一致する。

## 2. 生成から仕上げまで

AIの出力は「PS1風の絵」であって「320×180のドット絵」ではないため、必ず解像度を落として粒を粗くする。

| 工程 | 内容 |
| --- | --- |
| 1. 生成 | 1024×1024 程度で生成。プロンプトは下記テンプレート |
| 2. 切り抜き | 被写体を中央に、単色背景で生成。アルファを自動除去 |
| 3. 縮小 | 128×160（立ち絵）／32×48（スプライト）へ**最近傍で縮小** |
| 4. 減色 | 16色パレットへ量子化（ディザあり） |
| 5. 輪郭 | アルファ境界に1pxの暗色を付与（任意） |
| 6. 検収 | 1xで判別できるか。3xでドットが汚れていないか |

### 2.1 プロンプトのテンプレート

```
PS1 1998 low-poly survival-horror character, muted desaturated palette,
harsh top-left lighting, face mostly in shadow, no visible eyes, coarse
dithering, 32x48 sprite, plain background, no text, no logo,
Japanese 1990s small-town shopkeeper, side view
```

- 人物ごとに服装・年代・体格を差し替える。**スタイル句は固定**する。
- ネガティブ指定: `detailed eyes, anime, high resolution, smooth shading, realistic, text, logo`。

## 2.2 生成対象

| 種別 | 数量 | 備考 |
| --- | --- | --- |
| 調査スプライト（32×48） | 8 | 1人1枚。左右反転 |
| 立ち絵（128×160） | 8 | 1人1枚。表情差分なし |
| 証拠アイコン（16×16） | 9 | 生成またはコード描画 |
| UI枠 | 1 | 生成1枚（9スライス） |

- 表情差分は作らない。感情は姿勢（傾き・拡大）と台詞で示す。
- 泣き・怒りが必要な場面は、**顔を伏せる**（下向きの別カット1枚）で対応する。

## 4. 工数見積

| 項目 | 単価 | 数量 | 小計 |
| --- | --- | --- | --- |
| スプライト生成（3案 → 選定 → 自動処理） | 0.4h | 8 | 3.2h |
| 立ち絵生成（同上） | 0.5h | 8 | 4h |
| 後処理スクリプトの用意（縮小・減色・目潰し・輪郭） | - | - | 3h |
| 証拠アイコン・UI枠 | - | - | 2h |
| 検収・再生成（全体の40%を見込む） | - | - | 5h |
| **合計** | | | **約17時間** |

- Tier 1（涼・郷田・航＋顔伏せカット1枚）は約7h。
- 週10時間で2週間弱。

## 5. スコープ

| ティア | 内容 | 工数 |
| --- | --- | --- |
| **Tier 1: 縦切り** | 主要3人のスプライトと立ち絵、目潰し処理、UI枠、証拠アイコン | 約7h |
| **Tier 2: 章完成** | 残り5人のスプライトと立ち絵 | 約7h |
| **Tier 3: 調整** | 画風の統一、顔伏せカット、ノイズ調整 | 約3h |

## 6. 受け入れ基準

| 観点 | 基準 |
| --- | --- |
| 解像度 | 立ち絵 128×160、スプライト 32×48（実際のピクセル数） |
| 色数 | 16色以内（自動減色の結果で可） |
| 粒 | 3倍表示でドットが四角く見える。アンチエイリアスなし |
| 判別 | 1xで誰が誰か判別できる（体格・配色・帽子） |
| 一貫性 | 8人が同じ光源・同じ彩度・同じ粒 |
| 権利 | モデル規約が商用利用可。生成日とモデル名を記録 |

## 7. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| AIが目を描いてしまう | 画風の揺れ | 問題なし。そのまま採用。ネガティブ指定で誘導のみ |
| 縮小で潰れる | 誰か分からない | 3案から選ぶ。シルエット優先の構図 |
| 8人の画風が揃わない | 別作品の寄せ集めに見える | スタイル句固定＋基準画像。彩度と粒を後処理で統一 |
| 粗さが「手抜き」に見える | 評価が下がる | ディザと暗部の階調で密度を出す。UIは高解像度で締める |
| 権利・規約 | 公開停止 | モデル規約を確認し [[docs/asset-licenses]] に記録 |

# キャラクターグラフィック制作プラン

本ドキュメントは制作計画であり、実装・作画はまだ行わない。
寸法・フレーム数は [[docs/03_production/03_art-animation/2d-art-standards]] と
[[docs/03_production/03_art-animation/animations]] を正とする。

## 1. 方針

1. **グレーボックス先行**: 仮スプライト（単色シルエット）でゲームループを成立させ、後から差し替える。
2. **主要3人に集中**: 第1章の仲裁を成立させる涼・郷田・航に工数を寄せる。他は簡易版で成立させる。
3. **立ち絵は1枚の精度を優先**: 表情差分は眉・口・目の3点のみ差し替えで作る。
- **AI生成を第一候補、フリー素材を第二候補、手描きを補正手段**とする。対象は立ち絵・背景・アイコン。
- スプライトのアニメーションはAIで作らない。生成したベース1枚から、手作業でフレームを派生させる（一貫性を保つため）。
- 生成物は必ずパレット量子化とドット補正を施し、受け入れ基準を満たしたものだけを採用する。

## 3. 制作の順序

| 段階 | 内容 | 目的 |
| --- | --- | --- |
| A. スタイル確立 | 涼の正面・横向き、パレット確定、1枚の見本 | 以後の品質基準を固定する |
| B. 主要3人 | 涼・郷田・航のスプライトと立ち絵3表情 | 第1章の仲裁が「本物の絵」で成立する |
| C. 背景2面 | 中央通り＋組合事務所の2面（各3層） | 画面の基準露出を確認 |
| D. 残りの人物 | 立ち絵と簡易スプライト | 章の全シーンを埋める |
| E. 小物・UI | 証拠アイコン、ミス印、証拠スロット | 解決パートの可読性を担保 |
| F. 仕上げ | アニメーションのタメ・間、表情差分の追加 | 手触りの調整 |

**並行作業の原則**: 背景とキャラクターは別担当に分ける。キャラクターは「スプライト → 立ち絵」の順（立ち絵の方が修正コストが高い）。

## 4. 工数見積

| 項目 | 単価（時間） | 数量 | 小計 |
| --- | --- | --- | --- |
| フルセット（27フレーム前後） | 18h | 3 | 54h |
| 簡易セット（16フレーム前後） | 9h | 2 | 18h |
| 静止セット（5フレーム） | 3h | 3 | 9h |
| 立ち絵（1体目・ベース込み） | 5.5h | 8 | 44h |
| 立ち絵の表情差分 | 1.5h | 9 | 13.5h |
| 証拠アイコン | 1.5h | 9 | 13.5h |
| UI・エフェクト素材 | - | - | 16h |
| **合計（手描き基準）** | | | **約168時間** |
| **合計（AI生成＋補正）** | | | **約110時間** |

- AI生成を使う場合、立ち絵1枚は「生成3案 → 選定 → パレット量子化 → 手補正」で約2.5時間。8体＋差分9で約30時間まで下がる。
- 手描き基準では週10時間で約17週、AI活用時は約11週。Tier 3 まで含めると手描き約20週／AI約14週。
- 立ち絵（手描き57.5h）が最大の山。AI生成の品質が基準に届かない場合の保険として、フリー素材の利用も検討する。
- 背景（4面 × 3層）は別枠。[[docs/03_production/03_art-animation/background-art-plan]] を参照。

## 5. スコープの段階設定

| ティア | 内容 | 追加工数 | 完成時の状態 |
| --- | --- | --- | --- |
| **Tier 1: 縦切り** | 涼・郷田・航のスプライト＋立ち絵3表情、証拠アイコン9、UI一式（背景2面は別枠16h） | 約109h（AI時 約75h） | 第1章の仲裁まで本物の絵で通しで遊べる |
| **Tier 2: 章完成** | 残り5人の簡易/静止スプライトと立ち絵8枚、背景4面 | 約59h | 第1章が全シーン埋まる |
| **Tier 3: 仕上げ** | アニメ拡張、表情追加、小物挿絵 | 約30h | 配布可能な品質 |

プロトタイプの意思決定用には **Tier 1** を先に完成させる。Tier 2 以降は手応えを見て判断する。

## 6. ツールとパイプライン

| 工程 | ツール | 出力 |
| --- | --- | --- |
| 作画 | Aseprite（`.aseprite` を原本として保持） | PNG-8 |
| パレット管理 | 共通パレットファイル（32色） | `.gpl` / Aseprite パレット |
| 背景 | Aseprite / Photoshop（ドット等倍） | PNG-8（3層） |
| 書き出し | Aseprite CLI で一括書き出し | `public/assets/characters/` |
| 確認 | 1x / 2x / 3x の拡大表示、シルエットテスト | - |

- 原本（`.aseprite`）は `assets-src/` に置き、ビルド対象に含めない。
- 書き出し名は [[docs/03_production/01_conventions/naming-conventions]] に従う。
- 1アセットにつき1ファイル。レイヤー統合済みのPNGのみを `public/` に置く。

## 7. 受け入れ基準（Definition of Done）

| 観点 | 基準 |
| --- | --- |
| パレット | 32色以内。共通パレット外の色を使わない |
| 輪郭 | 1px。アンチエイリアス禁止。透過はアルファ1bit |
| 光源 | 左上固定。影の方向を全キャラで統一 |
| シルエット | 黒で塗り潰しても誰か判別できる |
| 縮小耐性 | 1x で顔のパーツが潰れない。3x でドットが汚れない |
| アニメ | ループの継ぎ目で位置がずれない。歩行で足が滑らない |
| 命名 | 規約どおり。`_new` / `_final` を使わない |
| ライセンス | 外注・外部素材は `docs/asset-licenses.md`（予定）に記録 |

## 8. 外注・AI の方針

| 手段 | 用途 | 判断 |
| --- | --- | --- |
| **画像生成AI** | 立ち絵17枚、背景レイヤー、証拠アイコン | **第一候補**。生成→量子化→手補正の工程を必須とする |
| **フリー素材（CC0/商用可）** | 背景の小物、UIパーツ、効果音素材 | 第二候補。ライセンスを確認し `docs/asset-licenses.md` に記録 |
| 自作（Aseprite） | スプライトの補正、アニメーション、UI | 生成物の補正とアニメ化は必ず手作業 |
| 外注 | 主要キャラの仕上げ | 品質が基準に届かない場合の保険 |

### 8.1 AI生成の運用ルール

- 1キャラにつき**基準画像を1枚確定**し、以後はそれを参照画像として生成する（同一性の担保）。
- 生成後に必ず行う: 背景透過 / 32色パレットへの量子化 / 1px輪郭の再描画 / ドットの粒ぞろえ。
- 3案生成して1案採用を基本とする。1案しか作らないと基準を満たさない確率が高い。
- 手・指・文字・ロゴは生成物に任せない（崩れるため、手描きか非表示で処理）。
- 生成物に既存作品・実在人物に似た要素が含まれる場合は不採用。
- モデルの利用規約で商用利用・再配布が許可されていることを確認し、モデル名と生成日を記録する。

### 8.2 フリー素材の運用ルール

- ライセンスは CC0 または商用利用可のものを優先。クレジット必須の場合は README に記載する。
- 1990年代日本の商店街という題材に合う素材は少ない。**背景の小物・汎用UIパーツに限定**して使う。
- 素材の混在で画風が割れるため、1画面内で生成物と素材を混ぜない。

外注時の契約事項: 著作権の譲渡、二次利用（PV・配信）の許諾、修正回数、納品形式（`.aseprite` + PNG）。

## 9. リスク

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 立ち絵の工数超過 | 全体日程が崩れる | Tier 1 では3人に限定。残りはシルエットで仮置き |
| パレットの揺れ | 画面の統一感が崩れる | スタイル確立（段階A）でパレットを固定し、以後変更しない |
| アニメの工数増 | スプライト制作が膨らむ | 状態を7→5に削る判断を段階Bで行う |
| 外注の品質差 | キャラの描き分けが崩れる | 1体目で必ずテスト発注し、基準を共有する |
| 権利処理の漏れ | 配布不可 | 受領時にライセンス記録を必須にする |
| AI生成の同一性崩れ | 同じ人物に見えない | 基準画像＋参照生成。3案採用制 |
| 生成物の権利・規約違反 | 公開停止 | モデル規約の確認と生成記録の保存 |

## 10. 未決事項

- バストアップ化に伴う立ち絵の画面配置（画面下 1/3 に収まるか）
- フリー素材の候補リスト（候補が出るまでAI生成で代替）

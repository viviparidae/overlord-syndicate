# アセット調達方針（人的リソース0）

## 1. 制約

- グラフィック・音声・UIを制作する**人的リソースは0**。
- 使える手段は **画像生成AI** と **フリー素材（商用利用可）**、および **コードによる描画** のみ。
- 手作業の作画・作曲・手直しを前提とした計画を立てない。

## 2. 原則

1. **手段がなければ設計を変える。** アセットが作れない表現は、演出をコードで代替するか、その表現自体を削る。
2. **自動処理に閉じる。** 生成物の後処理はスクリプト（減色・透過・リサイズ）で行う。手作業の補正を前提にしない。
3. **品質基準は「成立すること」。** 商業品質ではなく、第1章が読めて遊べることを合格とする。
4. **ライセンスを記録する。** AI生成物もフリー素材も、出典・規約・生成日を `docs/asset-licenses.md` に残す。
5. **人物・背景は同じ画風で揃える。** フリー素材の混在を避ける（UIアイコンは例外）。

## 3. 手段の割り当て

| アセット | 手段 | 手作業 |
| --- | --- | --- |
| 調査スプライト（32×48） | **画像生成AI**（1体1枚） | なし（自動処理のみ） |
| 立ち絵（128×160） | **画像生成AI**（1体1枚） | なし（自動処理のみ） |
| 背景（4エリア×2層） | 画像生成AI | なし |
| 証拠アイコン | フリー素材（game-icons.net 等） | 選定のみ |
| UI枠・ボタン | 画像生成AI 1枚＋コード描画 | なし |
| フォント | フリーフォント（日本語ドット系） | 導入のみ |
| BGM / SE / 環境音 | フリー音源（CC0 / クレジット表記型） | 選定のみ |
| アニメーション | **コード（トランスフォーム）** | なし |
| 画面演出（フラッシュ、ズーム、揺れ） | **コード** | なし |

## 4. やらないこと（削減リスト）

| 削減した項目 | 代替 |
| --- | --- |
| フレーム単位のドットアニメーション（27コマ/人） | 静止スプライト＋上下動・傾き・拡縮（[[docs/03_production/03_art-animation/animations]]） |
| 表情差分 | 作らない。目は描かなくてよい（描かれてもそのまま採用）。感情は姿勢と台詞で示す |
| 手前パララックス層 | 2層（遠景・中景）に削減。手前はコードで矩形シルエット |
| 夜差分の作画 | エンジンのティント（色調変更）で代用 |
| 証拠詳細の挿絵 | アイコン＋テキストのみ |
| ドット絵のUIパーツ群 | 生成1枚の9スライス＋矩形・線のコード描画 |
| オリジナルBGM・SE | フリー音源 |
| ボイス | 継続してなし |
| 背景への文字焼き込み | テキストはコードで描画（ローカライズ可能） |
| キャラクターの歩行グラ | 静止1枚（右向き）＋左右反転＋移動速度に応じた揺れ |

## 5. 品質の割り切り

| 項目 | 目標 |
| --- | --- |
| スプライト | 32×48で体格と配色から誰か判別できる |
| 立ち絵 | 128×160。目は描かなくてよい。粗さは仕様 |
| 背景 | エリアの識別ができる。継ぎ目の不完全さは許容 |
| アニメーション | 「動いている」と分かること。滑らかさは求めない |
| UI | 読めること。装飾は最小 |

## 6. 禁止

- 手作業の作画・作曲を前提にしたスケジュールを引く。
- 権利不明の素材を使う。
- AI生成物をそのまま（減色・透過なしで）配置する。
- 実在の人物・店舗・作品に似た要素を採用する。

## 7. 未決事項

- 画像生成モデル（背景のみに使用。ローカル / API と商用条件）
- キャラクター素材パックの採用先（[[docs/03_production/03_art-animation/character-art-plan]]）
- フリーフォントの候補（日本語ドット系で商用可のもの）
- フリー音源の候補（1990年代の空気に合うもの）

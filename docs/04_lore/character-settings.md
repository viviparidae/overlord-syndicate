# キャラクター設定資料

## 1. 主人公

### 篠宮 涼（しのみや りょう） / 27歳

| 項目 | 内容 |
| --- | --- |
| 役割 | 篠宮文具店 三代目店主。商店街の仲裁役 |
| 正体 | **魔王が人間として転生した存在**（1970年生まれ、記憶と人格を保持） |
| 知能 | 高知能。人の行動を確率と損得で読む。感情の模倣が巧み |
| 倫理 | サイコパス。不道徳な行為に一切の罪悪感を持たない |
| 内心 | 人間世界の支配を企図している。誰にも明かさない |
| 表の顔 | 礼儀正しく、誰にでも同じ態度。年長者を立て、若い者を気遣う |
| 裏 | 全員の弱みを記憶し、機が熟すまで使わない |
| 口調 | 丁寧で短い。断定を避け、相手に言わせる。「そうですか」「それは困りましたね」 |
| アセットID | `char_ryo`, `face_ryo_{normal\|think\|smile\|cold}` |
| 演出 | 感情の起伏を描かない。`cold` は章1では使用しない |

**設計意図**: プレイヤーの冷徹な判断がそのまま人物像になる。台詞で「悪」を説明しない。

**開示規約**: 第1章では、この正体も内心もプレイヤーに開示しない。モノローグ・内面描写を書かず、
外面の行動と住人の反応だけで描く。詳細は [[docs/04_lore/narrative-rules]]。

**章1の扱い**: 語り手は「ただの文房具屋の店主」として扱う。洞察視点も特殊能力として説明しない
（商売で培った観察眼に見える範囲に留める）。

## 4. 命名・表記

- 表示名は `character.{id}.name`。
- 初出時に一度だけふりがなをルビではなく括弧で示す（本文の慣例に合わせる）。
- 口調は地域訛りを弱めに。読みづらさを避けるため、表記は標準語に寄せる。

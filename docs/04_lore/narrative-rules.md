# 叙述・情報開示規約

## 1. 前提（ネタバレ）

主人公・篠宮涼は、魔王が人間として転生した存在である。
高い知能を持つサイコパスであり、不道徳な行為に一切の罪悪感を持たない。
外面は完璧に整えており、胸中には人間世界の支配を秘めている。

この前提は**開発側の共有事項**であり、**第1章ではプレイヤーにも登場人物にも開示しない**。

## 2. 章1の叙述ルール

| 項目 | 規定 |
| --- | --- |
| 視点 | 三人称。カメラは主人公の外側に固定する |
| モノローグ | **禁止**。内心の声、心象風景、比喩的な内面描写を書かない |
| 地の文 | 観察できる事実のみ（動作、視線、間、周囲の反応） |
| 台詞 | 外面の言葉のみ。本心を説明する台詞を書かない |
| 表情 | 感情の起伏を描かない。表情差分は持たない（姿勢と間で示す） |
| 選択肢 | プレイヤーの判断として提示する。善悪のラベルを付けない |
| 結果表示 | 誰がどうなったかだけを書く。主人公の感想を書かない |

プレイヤーが受け取る情報は、**住人の反応と、主人公が実際に取った行動**だけである。
「なぜそうしたのか」は章1では説明しない。

## 3. 許容する示唆

完全な無表情では人物が薄くなるため、次の2種類のみ許容する（章1で合計2箇所まで）。

1. **間（ま）**: 相手の台詞のあと、テキスト送りが0.5秒だけ遅れる。理由は語らない。
2. **視線**: スプライトの向きが、会話相手ではなく対象物（被害帳簿、VHS、郷田の事務所）へ一瞬向く。

示唆は「気づいたプレイヤーだけが拾える」強度に留める。説明や強調演出を付けない。

## 4. 開示スケジュール（予定）

| 章 | プレイヤーへの開示 | 作中の扱い |
| --- | --- | --- |
| 1 | なし | ただの文房具屋の店主として描く |
| 2 | 断片（他者の言葉による指摘、説明のつかない一致） | 住人の一部が違和感を覚える |
| 3 | 明示（プレイヤーには正体を提示） | 主人公は依然として誰にも明かさない |
| 4以降 | 前提として扱う | 支配の意志が行動の動機として描かれる |

- 章2の「断片」は、超常的な説明を付けない。偶然と観察力の範囲に留める。
- 開示の方法は、独白ではなく**他者との対比**で行う（例: 同じ状況で人が動揺する場面での落差）。

## 5. 禁止事項

- 章1で「魔王」「転生」「支配」「サイコパス」に相当する語を、本文・UI・ログのどこにも出さない。
- 章1のエピローグで、主人公の内面をほのめかす長台詞を書かない。結果は事実のみで示す。
- 「実は〜だった」という種明かしのナレーションを入れない。
- メタ発言（これはゲームである、主人公はプレイヤーの分身である等）を入れない。

## 6. 影響範囲

- 第1章のテキスト（導入・調査・解決・エピローグ）はすべて本規約に従う。
- キャラクター設定資料の「裏」欄は開発用の真実であり、ゲーム内テキストに直訳しない。
- 章1の結末でも、主人公の罪悪感や後悔を描かない。事実のみを提示する。

# ストーリープロット・年表

## 1. 世界観

平成9年（1997年）春。バブル崩壊から6年、地方都市・白鷺市の中心商店街は半分がシャッターを下ろしている。
再開発の噂が持ち上がり、土地を持つ者と借りる者の立場が静かに逆転しつつある。
誰もが「この街はもう終わりだ」と言い、誰もが最後の一滴を絞り取ろうとしている。

本作の主人公は、その街で唯一、客足の絶えない文房具店の三代目。礼儀正しく、物腰が柔らかく、誰からも好かれる。
彼が仲裁役として呼ばれるのは、本人が「公平」に見えるからだ。実際には、彼は全員の弱みを覚えている。

| 1997.04.12 | 臨時総会が招集される（第1章の当日） |

## 3. 第1章「消えた自治金」

### 3.1 事件

商店街のアーケード改修積立金から ¥300,000 が消えた。
金庫の鍵を持つのは組合長・辰巳徳造、会計・松谷静江、そして土地の権利書を預かる郷田権造の3人。
前夜、組合事務所に最後まで残っていたのは、住み込みで働く岡田修（19）だった。
噂は一日で「岡田が盗んだ」に収束しようとしている。

### 3.2 三幕構成

| 幕 | パート | 内容 |
| --- | --- | --- |
| 発端 | 導入 | 総会の招集通知。住人たちの視線。岡田の弁明を聞く前に、街は結論を出している |
| 侵食 | 調査 | 商店街を歩き、証言と物証のズレを集める。郷田の説明は丁寧だが、日付と金額だけが噛み合わない |
| 解決 | 仲裁廷 | 総会で郷田の証言を解体する。同時に、組合長と会計の小さな嘘も明らかになる |

### 3.3 真相

- 郷田は積立金 ¥300,000 を「再開発の測量費の立替」として持ち出し、実際には私的な用地買収の手付金に充てた。
- 帳尻を合わせるため、アーケード電灯の交換見積書を二重計上し、金額を積立金の不足分に近づけた。
- 金庫の鍵穴の傷は、郷田が合鍵を作らせた際のもの。岡田の犯行に見せるため、前夜に事務所へ入った形跡を残した。
- 岡田は前夜、事務所にいた。ただし理由は、松谷から頼まれた伝票の整理であり、金庫には触れていない。

### 3.4 決定的な証拠

| 証拠 | 何を崩すか |
| --- | --- |
| `ev_bank_slip` 振込控えの写し | 郷田の「積立金には触れていない」という証言 |
| `ev_estimate_dup` 二重計上の見積書 | 「不足分は電灯交換の値上がりで説明できる」という証言 |
| `ev_photo_arcade` 総会前夜の写真 | 「前夜は事務所に近づいていない」という証言（写真に郷田の車が映る） |

### 3.5 解決の代償

真相を暴いても、積立金は戻らない（既に手付金として支払われている）。
第1章の結末は「誰を守るか」で分岐する。

| 分岐 | 条件 | 結果 |
| --- | --- | --- |
| `epi_returned` | 3つのムジュンをすべて郷田に向ける | 郷田は土地の権利書を組合に預ける。岡田の疑いは晴れる |
| `epi_sacrificed` | 途中で松谷の証言を優先して指摘する | 松谷の横領（少額）が露見し、積立金の一部は戻るが、岡田は街に居られなくなる |
| `epi_quiet` | 追及のみで解決し、指摘を最小限にする | 郷田は黙って立ち去る。岡田の疑いは晴れないが、主人公は郷田の弱みを握る |

`epi_quiet` は「勝たない」選択。章2以降で最も大きな利得に接続する（伏線）。

## 4. 伏線

- 主人公が「公平」と呼ばれる理由は、誰の前でも同じ態度を取るから。その態度は訓練されている。
- 郷田の事務所にある電話番号のメモ（章1では読めない）は、章2の地方局の人物に繋がる。
- エピローグで主人公が金庫の鍵の複製をポケットに入れる描写（分岐により有無）。

## 5. トーン

- 事件は小さく、登場人物は狭い。世界の命運は扱わない。
- 感情の説明をしない。行動と台詞だけで関係を示す。
- 1990年代の小道具: ポケベル、公衆電話、貼り紙、手書きの収支表、コピー機のインクの匂い。

# ストーリープロット・年表

## 1. 世界観

平成9年（1997年）春。バブル崩壊から6年、地方都市・白鷺市の中心商店街は半分がシャッターを下ろしている。
再開発の噂が持ち上がり、土地を持つ者と借りる者の立場が静かに逆転しつつある。
誰もが「この街はもう終わりだ」と言い、誰もが最後の一滴を絞り取ろうとしている。

本作の主人公は、その街で唯一、客足の絶えない文房具店の三代目。礼儀正しく、物腰が柔らかく、誰からも好かれる。
彼が仲裁役として呼ばれるのは、本人が「公平」に見えるからだ。

### 1.1 主人公の正体（開発用・第1章では非開示）

彼は魔王が人間として転生した存在である。高い知能を持つサイコパスで、不道徳な行為に罪悪感を持たない。
完璧な外面の下で、人間世界の支配を企図している。第1章の時点では、この内面はプレイヤーにも登場人物にも開示しない。
叙述の詳細は [[docs/04_lore/narrative-rules]]。

## 3. 第1章「怒られたい少年」

### 3.1 事件

3ヶ月で5店・14件の万引き。防犯カメラはなく、目撃情報は「東口から歩いてくる中学生くらいの制服」だけ。
健太は後姿から「郷田の孫・航」だと確信し、噂は徐々に具体的になっていく。
郷田は「未成年の不祥事は内輪で済ませるのが礼儀」と主張し、組合に揉み消しを迫る。
住人の怒りは、犯人ではなく「揉み消そうとする郷田」に向かい始めている。
主人公は被害店主の代表として、商店街と郷田家の仲裁役を組合長から命じられる。

### 3.2 三幕構成

| 幕 | パート | 内容 |
| --- | --- | --- |
| 発端 | 導入 | 総会の招集と噂。航は何食わぬ顔で文房具店に来る。盗品は返品用の袋に入れて |
| 侵食 | 調査 | 被害の時刻・品目・痕跡を突き合わせる。盗品は全て日常品で、換金価値がない |
| 解決 | 仲裁廷 | 「万引き対策」の議題で郷田の言い分を解体し、航が盗む「理由」を暴く |

### 3.3 真相

- 犯人は航。ただし目的は金ではない。盗む品は全て文房具・本・電池など、必要とすれば自腹で買える物。
- 動機: 金で何でも解決してきた郷田家では、誰も航を「叱らない」。盗むことは、注目され関われる唯一の手段だった。
- 盗んだ物は全て航の部屋に残っている。売るという発想がなかった。
- 郷田は犯人が孫だと察している。それでも「外の人間がやった」という筋書を通そうとしており、
  時刻のアリバイと「金に困っていない」という主張で帳尻を合わせようとしている。
- 動機の裏側: 航は14歳で、少年審判や少年院の対象になり得る年齢。事件が表に出れば、再開発の地主としての信用が落ちる。郷田が必死なのは孫のためでもあるが、自分の土地のためでもある。
- 航は塾を辞めている（1997年2月）。岡田は「航は塾に行っている」と証言するが、知らされていない。

| --- | --- |
| `ev_ledger_theft` 被害帳簿 | 「犯人は金目の物を狙っている」（松谷）／「換金目的のはずだ」（郷田） |

### 3.5 結末（単一・分岐なし）

結末は1つ。プレイヤーの選択で変わるのは**到達の道筋と誤答回数だけで、結果は変わらない**。

- 3つのムジュンがすべて指摘され、郷田の言い分は解体される。
- 郷田は反論せず黙って退席する。揉み消しを指示したメモの写しが、机の上に残る。
- 航は総会の最後で、初めて顔を上げて話す。「売るつもりはなかった」。
- 積立金のような賞罰は出ない。組合は「被害届は出さない。店番を頼む」という形で決着する。
- エピローグ: 航が文房具店に通い、店番を手伝うようになる。主人公は誰にも言わず、揉み消しの記録を整理して引き出しにしまう。

主人公の内面は結末でも描写しない（[[docs/04_lore/narrative-rules]]）。結果の意味づけはプレイヤーに委ねる。

## 4. 伏線

- 主人公が「公平」と呼ばれる理由は、誰の前でも同じ態度を取るから。その態度は訓練されている。
- 郷田の事務所にある電話番号のメモ（章1では読めない）は、章2の地方局の人物に繋がる。
- 主人公が航に貸したノート1冊。エピローグで返ってくるページに、誰も読めない筆跡で一文が書き足されている。
- 机の引き出しにしまった揉み消しの記録。章2で主人公が郷田に「お願い」をする材料になる。

## 5. トーン

- 事件は小さく、登場人物は狭い。世界の命運は扱わない。
- 感情の説明をしない。行動と台詞だけで関係を示す。
- 1990年代の小道具: ポケベル、公衆電話、貼り紙、手書きの収支表、コピー機のインクの匂い。

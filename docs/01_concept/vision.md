# 企画書・コンセプト

## 1. 一行で

平成9年（1997年）、シャッター商店街の文房具店の若旦那が、
「弁論」という名目の討論で他人の嘘を解体し、少しずつ街の権力を握っていく物語。

## 2. 前作（第一弾）からの変更点

| 項目 | 第一弾 | 第二弾 |
| --- | --- | --- |
| 基盤コード | 流用する | **流用しない**（`proto/v2` は README のみから開始） |
| 中心システム | リソース管理＋コマンド選択 | **調査（横スクロール）＋解決（弁論）** |
| リソース | 資金／恐怖／狂信／警戒度 | **廃止**。解決パートのミスカウントのみ |
| 失敗 | 警戒度100でゲームオーバー | 解決パートで規定回数の誤答でゲームオーバー |
| 主人公の立場 | 支配者 | 章1では**ただの文房具屋の店主**（まとめ役） |
| テキスト量 | 大 | 章あたり 15〜20 分で読み切れる量 |

世界観・トーン・二面性の設計思想は継承する。数値リソースによる管理は行わない。

## 3. 体験の核

1. **見る**: 横スクロールの現場を歩き、配置された「調べられる場所」を潰していく。
2. **聞く**: 住人との会話から、言葉のズレ（誰が何を言い間違えているか）を拾う。
3. **突く**: 弁論で証言を聞き、手元の証拠と食い違う一行を指差す。
4. **握る**: ほころびを突いた結果、相手の弱みが手に入る。それが次章の前提になる。

「正しさ」を演じるほど、裏で握るカードが増える。これがシリーズ共通の快楽。

## 4. 三層構造

すべての章は次の順で進む。詳細は [[docs/02_game-spec/02_system-rules/game-loop]]。

```
導入（ストーリー） → 調査（横スクロール） → 解決（弁論） → エピローグ
```

- **導入**: ADV形式。失敗要素なし。事件の輪郭と人物関係を提示する。章1では主人公の内面を一切開示しない。
- **調査**: 横スクロール。聞き込み・痕跡調べ・証拠入手。詰みは作らない。
- **解決**: 証言のほころび指摘。誤答はミスカウント。上限到達でゲームオーバー。
- **エピローグ**: 結果の総括と次章へのフック。**分岐は存在しない**。

## 5. 差別化

- **法廷ではなく「総会」**: 弁護士でも検察でもなく、商店街組合の臨時総会が舞台。身内のいざこざを公開の場で裁く空気が1990年代らしい。
- **証拠が「物」である**: VHSテープ、手書きの被害帳簿、ノートの落書き、自販機のレシート。デジタル化前の証拠の扱いづらさが謎解きの手触りになる。
- **勝利が「支配」に接続する**: ほころびを突くほど、表向きは「頼れる若旦那」、裏では相手の弱みを握る。評判と支配が同じ行為から生まれる。

## 6. スコープ（プロトタイプ第二弾）

| 含む | 含まない |
| --- | --- |
| 第1章「万引き常習犯の更生」の導入・調査・解決 | 第2章以降の本実装 |
| 画面遷移、HUD、セーブ、ミスカウント | 課金・実績・多言語の完全対応 |
| 1ロケーション（商店街）の横スクロール | 複数ロケーション間の移動 |
| テキスト日本語のみ（en.json はキー構造のみ） | 音声収録・BGM/SEの実装 |

## 7. 非目標

- リソース管理シミュレーションに戻さない。
- メタナレーション（「これはゲームだ」と言及する演出）を入れない。
- 推理の詰みを作らない。調査パートは必ず全証拠が揃う。

## 8. 主人公（ネタバレ）

篠宮涼は、魔王が人間として転生した存在である。高知能のサイコパスで、不道徳な行為に罪悪感を持たない。
完璧な外面の下に、人間世界の支配という目的を隠している。

**第1章では、この正体も内面もプレイヤーに開示しない。**
プレイヤーが見るのは、礼儀正しい商店街の若旦那としての言動と、その結果だけである。
モノローグ、内面描写、種明かしのナレーションを使わない。詳細は [[docs/04_lore/narrative-rules]]。

この設計により、プレイヤーの「冷徹な最適解」がそのまま人物の内面として読める。
ゲーム側から性格を説明せず、行動の選択に意味を委ねる。

## 9. 参考

- 横スクロール探索の手触り: 『都市伝説解体センター』の探索パート。
- 証言・ほころび指摘のテンポは『逆転裁判』シリーズを参照するが、**語彙・演出・UIは模倣しない**（本作は法廷ではなく総会、弁護士ではなく店主）。
- ただし、本作は**失敗の重さ**を逆転裁判より軽くし、章単位のリトライを前提とする。

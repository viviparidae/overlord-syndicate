# Skill: game-balance-tuning

## 説明
データファイルを介してリソースコスト、獲得率、フェーズ閾値を調整する。

## 主要ファイル
- `src/balance/Costs.ts` — アクションコスト/リワードテーブル
- `src/balance/Thresholds.ts` — フェーズ遷移閾値、ゲームオーバー条件

## バランス哲学
- フェーズ 1: 低リスクのチュートリアル。警戒度上限 30。
- フェーズ 2: メディアハックを導入。警戒度上限 60。
- フェーズ 3: 国家レベル。警戒度上限 85。
- フェーズ 4: グローバル。勝利/警戒度 100 で決着。
- フェーズごとの恐怖上限: 30 / 60 / 85 / 100 (警戒度が急上昇する前のソフトリミット)
- リソース獲得率はフェーズ進行速度と釣り合わせる
- 各コマンドには意味のあるJPYコストとリソース変化を設定する

## 制約
- 分岐ロジックを追加しない — `Costs.ts` と `Thresholds.ts` は純粋なデータテーブル
- すべての値は数値的に決定論的でなければならない（バランス内で `Math.random()` 禁止）
- フェーズ遷移閾値は通常のゲームプレイで到達可能でなければならない
- 警戒度 100 への到達は、他のリソースの蓄積ではなく、意図的な恐怖の蓄積によってのみ行う
